# Kiki GUI Agent Guide

- Visual acceptance uses the headless proof runner by default (`node apps/kiki-gui/scripts/visual-proof.mjs --config apps/kiki-gui/scripts/visual-proof-headless-smoke.mjs`, or `--scenario <fixture> --vite` to launch and tear down Vite + fixture server automatically). Never depend on a desktop window unless testing a third-party logged-in site or native WebView (`kiki-desktop-ops`); if an Ego capture is unavoidable, restore the agent-owned window first via `Browser.getWindowForTarget` + `Browser.setWindowBounds({ windowState: 'normal' })` and never touch another user's TaskSpace.
- Reuse `src/components/message/EditUserRow.tsx` across transcript views and `src/test/connectedTranscriptFixture.tsx` in editor interaction tests.

## 4-Zone Shell, `h-12` Datum & Subtraction-First `<Composer />` Standard

1. **Zone 1 — Sidebar `18px` Keyline, Hairline Mode Bar & Two-Tier Bell**: `Sidebar.tsx`, `SpaceSwitcher.tsx`, and `SidebarModeSwitch.tsx` (`待办 | 会话` bottom-border tabs with inline running indicator and filter/view icons; zero duplicate section `<h2>`) align on a single `18px` left keyline (`pl-[18px] pr-2.5` header; `px-2.5` outer + `px-2` row + `w-5` icon slot). `+ 新会话` uses a `20×20` `rounded-full bg-accent/12 text-accent-ink` `+` mark. The activity bell shows an inset `bg-attention` count when `needsYou.length > 0` and a quiet `7px` `bg-ink-soft/65` dot for finished unread runs (`data-activity-badge={inbox.total}`).
2. **Zone 2 — Continuous 3-Pane `h-12` Header & `AgentFamilyPopover`**: `WorkspaceHeader` is single-row `h-12` (`border-b border-hairline/70`). `AgentWorkspaceHeader` renders inline ancestor crumbs + a single `<h1>` leaf opening `@base-ui/react` `AgentFamilyPopover`, inline running-children `● N` pill, branch badge, and `[合回主线]` (`data-branch-fold-action`) — no duplicate `<h1>`, header `model·effort`, `data-agent-relations-surface`, or floating `data-branch-fold-bar`.
3. **Zone 3 — Right Inspector `h-12` Hairline Tabs (`运行 | 配置`)**: `[data-rail-pinned]` is `h-12`. When `sameAsCenter`, `[data-rail-owner]` renders `运行` (`[data-rail-tab="run"]`) and `配置` (`[data-rail-tab="config"]`, `1.5px` `bg-ink` underline, quiet `5px` `bg-attention` dot only on actionable config updates), sr-only `<h2 tabIndex={-1} data-rail-owner-heading>`, `[data-rail-pending-jump]`, and `[data-rail-close]`. Subagent peeks render `RailCrumbs` in `h-12` + sticky `h-8` `[data-rail-sub-tabs]`. Cockpit mode is retired. `运行` scrolls `NeedsYouList`, `ProfileHead` + `InspectorNow`, compact `用量` (details in tooltips), `会话分叉`, `待办` (`line-clamp-2`), active `后台任务`, `智能体`, and a bottom history fold (`工作笔记`, settled `后台任务`, `动态`, `沟通`). `配置` renders compact SVG `RailLiveTopology` (`0px` when idle), main-only unfolded controls (`系统能力`, `插件` with `>2` disabled folded, `MCP`, `通信信道`, `定时任务`, `角色设定`), and folded `自动规则` / `能力` / `会话`. Thinking effort uses `formatThinkingEffort` (`src/lib/thinkingEffort.ts`).
4. **Zone 4 — Subtraction-First `<Composer />`**:
   - `[data-composer-body]` holds at most 3 rows: optional edit banner or `h-11` `[data-context-tray]` (`pt-2 pb-1`), `<ComposerInput />` (humanized `@Thread · <short>` pills), and `[data-composer-toolbar]` (`Stop` when `busy && !canSend`, `[↑ | ▾]` when `busy && canSend`, `<480px` `CompactModelSheet`). Mode lives solely in `RunModeChip` + `data-run-mode`.
   - Plugin panels live only in top-right `WorkspacePanelsControl` + `/` completion: `<= 4` `open_plugin_panel` slots render as direct 1-click header buttons (`hidden xl:inline` labels + per-plugin status dot), overflowing `> 4` into `Popover` (`data-workspace-panels-trigger`), alongside `[预览]` (`data-preview-toggle`).
   - Resident SSH (`[data-composer-ssh-strip]`) and `<PluginStatusCapsules />` sit in `[data-composer-status-line]` below the card.
