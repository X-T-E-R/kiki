# Kiki GUI Agent Guide

- Kiki GUI visual acceptance uses the headless proof runner by default; it never depends on an Ego Lite or desktop window. Use `node apps/kiki-gui/scripts/visual-proof.mjs --config apps/kiki-gui/scripts/visual-proof-headless-smoke.mjs` for the checked-in smoke matrix, or pass `--base-url <url> --token <token> --route <name=/path> --theme light,dark --locale en,zh --viewport wide,narrow` for an existing GUI server. Omit `--base-url` and add `--scenario <fixture> --vite` to start and clean up Vite plus the fixture server automatically.
- Use Ego Lite / a desktop browser only for a third-party site that needs the user's login state or a real desktop WebView. If an Ego capture is unavoidable, restore an agent-owned target before the screenshot with `Browser.getWindowForTarget` and `Browser.setWindowBounds({ windowState: 'normal' })` (for example: `const { windowId } = await task.cdp('Browser.getWindowForTarget', { targetId: page.targetId }); await task.cdp('Browser.setWindowBounds', { windowId, bounds: { windowState: 'normal' } });`). Never touch another user's TaskSpace. Real desktop executable acceptance follows the `kiki-desktop-ops` process.

## 4-Zone Shell, `h-12` Datum & Subtraction-First `<Composer />` Standard

1. **Zone 1 — Sidebar `18px` Keyline & Two-Tier Bell**: `Sidebar.tsx` and `SpaceSwitcher.tsx` align on a single `18px` vertical left keyline (`pl-[18px] pr-2.5` header row; `px-2.5` outer + `px-2` row + uniform `w-5` leading icon slot across all lower sections). `+ 新会话` is a flat rail row with a `20×20` `bg-accent/12 text-accent-ink` circular `+`. The activity bell uses a two-tier inset signal: `needsYou.length > 0` displays an inset `bg-attention` count (`top-1 right-1`), while finished unread runs with `needsYou === 0` show a quiet `7px` inset dot (`bg-ink-soft/65`) with zero numeric text (`data-activity-badge={inbox.total}` preserved).
2. **Zone 2 — Continuous 3-Pane `h-12` (`48px`) Header & `AgentFamilyPopover`**: `WorkspaceHeader` is always single-row `h-12` with `border-b border-hairline/70`. `AgentWorkspaceHeader` renders inline ancestor crumbs + a single `<h1>` leaf trigger opening `@base-ui/react` `AgentFamilyPopover` (Parent / Children / filtered Siblings in both `showBreadcrumb=true` and `showBreadcrumb=false` modes), with inline running-children `● N` pill, quiet branch seam badge, and `[合回主线]` (`data-branch-fold-action`) on the right (no duplicate `<h1>`, no header `model·effort`, no `data-agent-relations-surface`, no floating `data-branch-fold-bar` above `<Composer />`).
3. **Zone 3 — Right Inspector `h-12` Sticky Bar**: `[data-rail-pinned]` is strictly `h-12`. `NeedsYouList` (with a `● N` jump pill in `h-12`), `ProfileHead`, and `InspectorNow` scroll inside `.rail-page`. When inspecting the center agent (`onInspectMain === undefined`), `[data-rail-owner]` renders a single `<h2 tabIndex={-1} data-rail-owner-heading>` (`Overview` / `Cockpit`) instead of repeating `RailCrumbs`. Thinking effort labels share `formatThinkingEffort(effort, t)` (`src/lib/thinkingEffort.ts`).
4. **Zone 4 — Subtraction-First `<Composer />` (`2–3 Rows Max Inside Card`)**:
   - Card interior (`[data-composer-body]`) holds at most 3 rows: (1) optional transient edit banner (`queueEditing`) or a single-row `44px` (`h-11`) horizontal scroll shelf (`[data-context-tray]` -> `[data-context-shelf]` with `pt-2 pb-1` headroom so corner `×` badges never clip), (2) unobstructed `<ComposerInput />` (rendering unresolved `[[thread:...]]` / `[[room:...]]` inline as humanized `@Thread · <short>` pills), (3) calm bottom toolbar (`[data-composer-toolbar]` — single `Stop` when `busy && !canSend`, explicit `[↑ | ▾]` split Send/Timing when `busy && canSend`, `<480px` `CompactModelSheet`).
   - Mode lives in one place (`RunModeChip` + `data-run-mode` ring + placeholder; no `data-goal-armed` top banner).
   - Plugin panels live in the header `WorkspacePanelsControl` (`SessionView`, `AgentWorkspace`, `NewSessionPage`) + `+` (`AddMenu` Extensions supporting all 4 action kinds) + `/` slash completion — never inside `<Composer />`.
   - Resident SSH hosts (`[data-composer-ssh-strip]`) and active `<PluginStatusCapsules />` live in the bare external `[data-composer-status-line]` below the card (`>_ host +N ▾` opening upward via `@base-ui/react` `Popover` `side="top"`).
