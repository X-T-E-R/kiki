Submit the finished plan and leave plan mode. The plan is read from the plan file named in the plan reminder, so write it there first; do not pass the plan text as a parameter. Write steps that can be checked. Use `options` only when the plan offers real alternatives; give each a distinct label other than Approve, Reject, Reject and Exit or Revise, because those name the review's own buttons. By default plan mode ends at once without a user review, and the result says so: follow the user's original instructions about whether to start implementing. When plan review is turned on and the session is in manual mode, the user reviews the plan first; if they reject it, revise the file and call again. The plan is shown to the user when you call this tool, so do not use AskUserQuestion only to ask whether it is acceptable.
