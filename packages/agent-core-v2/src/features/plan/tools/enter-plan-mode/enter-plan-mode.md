Enter plan mode to research and draft an implementation plan before a consequential change with competing approaches or substantial uncertainty. Skip it for a small fix, a well-specified task, or pure research. The plan reminder explains the workflow; use ExitPlanMode after writing a concrete, verifiable plan. In plan mode, only the plan file can be edited; new native research-readonly children are permitted, but resuming or messaging children is blocked. Bash retains normal permission rules; this is not a sandbox.
