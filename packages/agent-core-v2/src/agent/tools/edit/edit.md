Replace exact text in an existing file. `old_string` must match the file character for character, including indentation, and must occur exactly once; add neighbouring lines to make it unique, or set `replace_all` to change every occurrence. Copy it from Read output without the line-number prefix. To make several changes to one file in one call, pass `edits` instead: each entry has its own `old_string`, `new_string` and optional `replace_all`, the entries apply in order, each to the result of the previous one, and the file is written only if every entry succeeds. A prior Read is not required, but `old_string` must be the file's current text: if you have not read the file, or it changed on disk after you last read it, the edit is still applied when `old_string` matches, and the result says so. A successful result gives the changed line numbers. A failed one says why `old_string` did not match and, where it can, which lines to look at. A file with CRLF line endings is shown with LF and written back with CRLF. Where Read shows a literal `\r`, the file has mixed endings and `old_string` must contain that `\r`.
