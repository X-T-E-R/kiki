Return a background task's status and its output so far. It answers immediately and never waits. Without paging arguments it returns the last 32 KB of output; for the whole log, Read the `output_path` in the result, or page with `offset` and `max_bytes`, both counted in bytes. A shell task succeeded only if its exit code is 0; `terminal_reason` tells a timeout or a stop apart from an ordinary failure. You are notified when a task finishes, so there is no need to call this repeatedly while waiting. Use TaskList if you no longer have the task id.
