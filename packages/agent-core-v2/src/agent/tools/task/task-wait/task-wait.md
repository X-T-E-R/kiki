Pause this turn until a background task finishes or `timeout` seconds pass (required, 1 to 86400). With `task_id` it waits for that task, whether a shell, a subagent or another background task. Without `task_id` it waits for whichever task running now finishes first; as the main agent outside goal mode, subagent tasks are left out of that wait because their results reach you by notification, and the result names the ones it did not wait for. Reaching the timeout is not an error and leaves the tasks running. You are notified when tasks finish, so wait only when the next step of this same turn needs the result; otherwise do other work or end the turn and continue when notified. A result delivered by this call is not notified a second time. A subagent should settle its own tasks before returning, because its parent sees only its final result.
