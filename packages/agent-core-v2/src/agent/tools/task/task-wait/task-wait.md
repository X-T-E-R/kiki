Wait for an owned background task to finish within the current turn; `timeout` is required. Use only for a genuine same-turn dependency, not to poll an automatically notifying task. Without `task_id`, returns when any task running at call time finishes; with one, waits for that task. A timeout leaves tasks running. A task reported here does not also send an automatic completion notification. Subagents must resolve their own dependencies before returning a final receipt.
