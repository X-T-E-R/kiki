Background child launch is unavailable because TaskList, TaskOutput, and TaskStop are not enabled. Main still defaults to background, including resume and goal mode: an omitted `background` or explicit `background=true` call is rejected before launch, with no synchronous fallback. Enable those tools, or set `background=false` explicitly for a genuine same-turn dependency. Subagents may omit `background` to wait in foreground. New steer / Send now input releases a main foreground wait without stopping the child; its completion arrives through automatic notification.
