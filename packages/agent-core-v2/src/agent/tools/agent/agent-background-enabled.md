Omitting `background` runs in background for main and waits in foreground for subagents, including resume and goal mode. In-session branches follow main's background defaults, 15s auto-detach, and steer-release behavior. On main or branch, keep `background` omitted (or `true`)—`background=true` returns a task receipt and delivers the result through automatic completion notification; `background=false` is only for subagents or profiles without background task tools. If main or branch starts a foreground wait outside active goal mode, it automatically detaches into background after 15s without stopping the child, and new steer / Send now input releases foreground waits into background immediately for main, branch, and subagents with background task tools. Outside active goal mode, main should do independent work or end its turn while waiting—the task and session continue. Do not poll TaskWait/TaskOutput/AgentList just to keep a main turn open. A subagent must resolve its own dependencies before sending its final receipt.
