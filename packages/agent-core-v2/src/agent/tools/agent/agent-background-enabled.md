Omitting `background` runs in background for main and waits in foreground for subagents, including resume and goal mode. Set `background=false` explicitly for a genuine same-turn dependency; `background=true` returns a task receipt and delivers the result through automatic completion notification. New steer / Send now input releases a main foreground wait into background without stopping the child. Outside active goal mode, main should do independent work or end its turn while waiting—the task and session continue. Do not poll TaskWait/TaskOutput/AgentList just to keep a main turn open. A subagent must resolve its own dependencies before sending its final receipt.
