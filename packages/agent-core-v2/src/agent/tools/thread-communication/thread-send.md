Give an independent colleague the decision, stable input, usable artifact, correction, or dependency it still needs for your shared work. Digest evidence and send the relevant change, not raw receipts, unrelated progress, or scheduling narration. Use the channel naturally for discussion or conversation the user requests; there is no fixed message quota or reporting template.

Pass `thread` to message another thread in this home, or an approved one-way space bridge (`bridge_id` / `connection_id`). The message is stored as a peer message from this thread. `delivered` means it joined the running turn or started one, `pending` means it is waiting in that thread, and `undeliverable` means it was rejected. A cold thread can resume. A bridge delivers into a model turn when it has wake authority; with send authority alone the message stays pending. Address a thread other than this one. `idempotency_key` retries the same content. Pass `notify_on_terminal: true` (thread targets only, rejected with `room`) ONLY when delegating a bounded async job to a target that will not explicitly reply via `ThreadSend`: it watches the target in the background and automatically notifies this thread once the target settles (waiting for its active subagents and finite background tasks on completion), needs attention, or terminates (waking this thread if idle; bridged targets require `wait` permission). Do not set `notify_on_terminal: true` on routine peer replies, status syncs, or ongoing back-and-forth discussions; an explicit peer reply from the target back to this thread automatically cancels any armed send watch. ThreadWait watches that colleague's later activity. Pass `room` instead of `thread` to speak in a room this thread belongs to: `{room, content, mentions?}`. Mentions use exact member IDs (thread session id or persona id), not display names. A user message with no mention goes to the room host. A message from a member wakes only the members it mentions. Room `delivered` means the room log has the message. The room retry key is the tool call id when `idempotency_key` is omitted. Thread members queue while busy; a successful catch-up covers older queued notifications. Text in this thread stays in this thread; ThreadSend is how you speak in the room.
