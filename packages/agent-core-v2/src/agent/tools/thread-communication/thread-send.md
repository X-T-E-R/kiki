Give an independent colleague the input it needs. Pass `thread` to message another thread in this home, or an approved one-way space bridge (`bridge_id` / `connection_id`). The message is stored as a peer message from this thread. `delivered` means it joined the running turn or started one, `pending` means it is waiting in that thread, and `undeliverable` means it was rejected. A cold thread can resume. A bridge delivers into a model turn when it has wake authority; with send authority alone the message stays pending. Address a thread other than this one. `idempotency_key` retries the same content. ThreadWait watches that colleague's later activity. Pass `room` instead of `thread` to speak in a room this thread belongs to: `{room, content, mentions?}`. Mentions use exact member IDs (thread session id or persona id), not display names. A user message with no mention goes to the room host. A message from a member wakes only the members it mentions. Room `delivered` means the room log has the message. The room retry key is the tool call id when `idempotency_key` is omitted. Thread members queue while busy; a successful catch-up covers older queued notifications. Text in this thread stays in this thread; ThreadSend is how you speak in the room.
