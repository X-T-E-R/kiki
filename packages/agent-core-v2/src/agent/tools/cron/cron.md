Manage prompts scheduled in this session: action=create, list, or delete. Create uses a local-time 5-field cron expression (minute hour day month weekday), `prompt`, and `recurring` (default true; false fires once). Optional `delivery_mode` chooses `idle` (default: after current work, before ordinary queued messages, merge repeated waiting fires with their count), `queue` (each delivery in normal order), or `steer` (next safe step without interrupting the current request). Optional `trigger` checks `probability` (`0`–`1`, evaluated first) and/or an owner-registered `script` ID before admitting the prompt; skipped checks advance the schedule cursor without starting a turn. For a single future date, set `recurring: false` and pin minute/hour/day/month. A recurring task auto-expires after its seventh day; recreate it if still wanted. List returns ids, next fire times, triggers, and latest check outcomes; delete requires a listed id and cannot be undone. Schedules survive an unloaded session but do not carry into a new one.
