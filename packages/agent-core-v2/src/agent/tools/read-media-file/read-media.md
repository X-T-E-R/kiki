Read an image, video, or audio file, not text. Read newly generated media back before reporting it. For images, the result gives the original dimensions and whether the image was downsampled. If fine details matter, use `region` with coordinates in the original image; `full_resolution` skips downscaling for images (when within the per-image byte limit) and skips local pre-compression for oversized inline video or audio. If an image exceeds the limit, create a smaller copy or crop before reading it again.
