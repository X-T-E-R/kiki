List this agent's direct children, not grandchildren; use it to rediscover a child name or id after compaction before AgentRun resume or AgentSend. Default `include_finished=false` includes running and idle children; pass true for completed ones. Results are bounded by `[subagent].agent_list_limit` (32 by default, active and pending children prioritized first) with an omitted count when more exist; pass `query` (case-insensitive substring over `name`, `agent_id`, `profile`, `model`, and `status`) or `limit` (1–200) to locate a specific child across large rosters. Entries always report `agent_id`, `status`, and optional `name`, `profile`, and `persistence_failure`; read-only telemetry fields (`model`, `thinking_effort`, `elapsed_ms`, `idle_ms`, `tool_call_count`, `context_tokens`) follow `[subagent].agent_list_fields` (`model`, `elapsed_ms`, `idle_ms`, `tool_call_count` by default), are omitted when unavailable, and are all included when `raw=true`. A child's `running` status does not guarantee an active background task or notification—use TaskList for tracked work. This is a read-only roster and does not start or message children.
