Manage this agent's task progress and working notes independently. Send only what changed: omit todos to keep the list, omit notes to keep all notes, and omit a notes section to keep that section. Omission means unchanged, not deletion. Call with {} to read both.

Use short, actionable todos for multi-step work; skip them when tracking adds no value. While working, keep exactly one item in_progress. Mark an item done only when its completion criteria and relevant checks are met; keep blocked or failing work active. A supplied todos array replaces the whole list, so include every item still needed. todos: [] clears only the list.

For longer work, use notes for the current goal, active task constraints, decisions, evidence pointers, and next action. Supply only changed sections. Each supplied string replaces that entire section: keep its still-valid content, conditions, and exceptions. notes: {"next":"..."} changes only next and leaves todos and other sections unchanged. Use "" only to delete that section and notes: null only to clear all notes; never use clearing values as placeholders.

Reuse complete, current content already in view; read before replacing a section whose current content is missing. Notes belong to this agent in this session and survive context compaction; do not recreate them from a summary or rewrite them merely because a reminder fired. After checking the handoff and human input against current notes and original sources, set review_handoff: true to acknowledge that boundary, with any needed section changes. A normal notes update does not acknowledge the handoff. For cross-task guidance, use available memory tools under their scope and approval rules instead of treating task notes as saved memory.

Writes return a compact receipt with changed fields and revision, not the full state. Use {} only when you need the current contents; do not read back after every successful write.
