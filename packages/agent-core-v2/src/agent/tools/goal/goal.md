Manage an autonomous, multi-turn goal: action=create, get, or update. Create only when the user explicitly requests autonomous goal work; give it a verifiable objective of at most 4,000 characters (reference long details by file path), and use replace only with authorization, because creating fails while an active, paused or blocked goal exists. In manual permission mode the user reviews the new goal before it starts and may choose the permission mode it runs in; if the user rejects it, the goal is not created. Get shows current status and remaining budget. Budgets default to unlimited and can only be changed by the user in the GUI goal editor, not through tools or natural-language requests. Token usage counts this agent's goal output, not context size, total billed tokens, or the agent tree. Update with status=complete or status=blocked only after checking the actual outcome; do not mark partial work complete. status=active resumes a paused or blocked goal and is refused for a goal that is already active. Use blocked for a demonstrated impasse requiring user input or an external change after reasonable local diagnosis; do not retry an unchanged blocker merely to reach a turn count.
