Manage an autonomous, multi-turn goal: action=create, get, set_budget, or update. Create only when the user explicitly requests autonomous goal work; give it a verifiable objective, and use replace only with authorization. Get shows current status and remaining budget. Set_budget requires a user-given turns/tokens/time limit. Update with status=active, complete, or blocked only after checking the actual outcome; do not mark partial work complete. A nonterminal blocker must persist for three consecutive goal turns before blocking.
