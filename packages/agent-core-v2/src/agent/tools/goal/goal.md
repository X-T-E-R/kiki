Manage an autonomous, multi-turn goal: action=create, get, or update. Create only when the user explicitly requests autonomous goal work; give it a verifiable objective, and use replace only with authorization. Get shows current status and remaining budget. Budgets default to unlimited and can only be changed by the user in the GUI goal editor, not through tools or natural-language requests. Update with status=active, complete, or blocked only after checking the actual outcome; do not mark partial work complete. A nonterminal blocker must persist for three consecutive goal turns before blocking.
