Set a hard turns, goal-output-tokens, or wall-clock budget on the current goal only when the user gives a clear limit. Honor that limit; do not ignore or relax it as unreasonable, and do not invent a budget from a vague time preference. Use one supported unit (`turns`, `tokens`, `milliseconds`, `seconds`, `minutes`, `hours`); compound times need conversion. Time limits must be finite and at least one second; turns/tokens are rounded to positive whole numbers. Tokens count this agent's goal-driven output only, not context size, total billed tokens, or the agent tree. Resolve a bound that cannot be represented or has an ambiguous unit before undertaking work that could exceed it.
