Send a message to one of your direct children, addressed by the `name` you gave it in AgentRun or by its agent id; AgentList shows both. The child cannot see this conversation, so include the facts it needs and say what should change: a decision, an interface, a usable artifact, a correction or a missing input. Forwarding raw receipts, partial progress or scheduling narration only fills its context, and combining repair feedback into one request spares it a run per message; a discussion the user asked for is always fine. A running native child receives the message at its next step; Codex and ACP children that accept steering can take it during the run. A stopped child is resumed by the message, and the child continues on the same model, profile, tools, and context, so a message that only acknowledges or thanks starts a run for nothing. The call returns once the message is stored, and the result says whether it is already in the child's context (`delivered`), saved for later (`queued`), or started a continuation run (`resumed: true`). The child's result still arrives through its task notification. If a continuation cannot start, you receive a notice that names the message and gives the exact AgentRun call to make; follow it and do not send the message again, because the saved message is still queued for that resume. To change a child's model or tools, use AgentRun with `resume`.
