Send a direct child the input it needs to continue. Address it by its AgentRun name or agent id; AgentList lists those names. The message carries the facts and the outcome you want, because the child does not see this conversation.

While the child is running, the message joins that work. A native child takes it at the next step boundary. Codex, and an ACP child that accepts steering, can take it during the run. When the child has stopped, or its run ends before the message is in context, the child continues on the same model, profile, tools, and context. That continuation is the same path as AgentRun resume. Use AgentRun when you need to change the binding.

This call returns when the message is saved. `queued` means the message is saved and not yet in the child's context. It does not mean a run is in progress. `delivered` means it is in the child's context. `resumed` means a continuation run was observed starting. The child's task and its completion notice are the run's result. Saved messages for one child stay in order and enter that same binding. If a continuation cannot start, this call still returns the saved message, and you then receive the reason, the error code, the target, and this message id. Resume that same child with AgentRun: set resume to the target agent id, set prompt to an empty string, and set description to a short label. The saved message stays queued and enters that resume. Do not call AgentSend again, do not repeat the saved message in the prompt, and do not set new_window. A failed external resume does not open a new remote session.
