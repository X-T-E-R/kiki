Queue a message for a direct child by its AgentRun name or agent id; use AgentList if unsure. A running native child receives it at a step boundary; an idle resumable child starts a background run. Running external children read queued mail on their next run. A queued result means delivery has not necessarily happened; this tool does not wait. Names must be unambiguous, and the child does not see your conversation, so provide context in the message.
