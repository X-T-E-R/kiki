Fetch or extract content from a URL, or locally scoped/inline readable text. Use FetchURL after WebSearch when the source's full text matters. Minimal sync URL call: `{ "url": "https://example.com" }`; `source` calls default `action` to `"run"` and must not mix with URL shorthand. Local/inline content cannot use egress pipelines; file inputs need an admitted donor scope and are bound to the approved file identity. Async requires `idempotency_key`; use get/read/cancel for the receipt and preserve partial/truncation warnings. Authentication walls do not become authenticated content.
