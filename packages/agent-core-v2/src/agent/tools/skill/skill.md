Load a skill by its listed name (`skill`) or from a Markdown file (`path`); give exactly one. When a listed skill matches what the user asked for, load it before doing the work, because the skill holds the instructions for that kind of task. The call returns a one-line confirmation and the skill's instructions arrive as the next message, in a `<skill-loaded>` block. `args` is passed to the skill like a command line. If a `<skill-loaded>` block for the same file (compare `path` or `dir`, not only the name) with the same `args` is already in this conversation, follow it instead of loading it again; load again when the `args` differ, because the block was expanded with the earlier ones. A skill marked for user invocation only cannot be loaded this way, from a name or a path. Loading from `path` affects this call only: it does not replace a listed skill of the same name, install a plugin or run scripts. Relative resources resolve from the loaded file's directory.
