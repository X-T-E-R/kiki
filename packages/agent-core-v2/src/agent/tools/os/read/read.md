Read a text file (UTF-8 or UTF-16) at a known path, or list a directory. Relative paths resolve against the working directory. Each call returns up to ${MAX_LINES} lines and at most ${MAX_BYTES_KB} KB, and lines longer than ${MAX_LINE_LENGTH} characters are cut. Page with `line_offset` and `n_lines`: `line_offset` counts from 1 (0 reads from line 1), and a negative value starts that many lines before the end, down to -${MAX_LINES}. Every output line starts with its line number and a tab, which are not part of the file. The closing `<system>` line reports the range read, the total line count when known, the file size in bytes, and, when more lines follow, the `line_offset` to continue from. A directory path returns its entries one level deep, with subdirectories marked by a trailing `/` and secret files left out. Images and video are refused; view them with ReadMediaFile when that tool is available. Other binary files are refused. Reading a secret file such as `.env` or an SSH key asks the user for approval unless the session is in YOLO mode. Write can replace an existing file only after you have read it, in whole or in part, and only while it is unchanged since; Edit needs no prior read.
