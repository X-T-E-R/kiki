Search file contents with ripgrep regular expressions. To match `(`, `[`, `{`, `.`, `|`, `*`, `+` or `?` literally, escape them with a backslash, or set `literal=true` to search for plain text. `path` limits the search to one file or directory; `type` (for example `ts` or `py`) or `glob` limits it by file, and a `glob` containing `/` is anchored at the search directory. `output_mode` chooses the result: `files_with_matches` (default) lists paths, most recently modified first; `content` lists matching lines as `path:line:text` and accepts `-A`, `-B` and `-C` for context; `count_matches` lists counts per file. At most `head_limit` entries come back (default 250); when more exist, the result states the total and the `offset` that continues. Returned paths are either absolute or relative to the working directory, so they can be passed to Read unchanged. Hidden files are searched. Files excluded by `.gitignore` are skipped unless `include_ignored=true`. `.git` and secret files such as `.env` are always left out. A search that runs longer than 20 seconds stops, and the result says so and includes what was found by then.
