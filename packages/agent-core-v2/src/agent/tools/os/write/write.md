Create a file, replace its whole content, or append to it. Missing parent directories are created. `mode=append` adds the content exactly as given, without a newline. Replacing a file that already exists requires that you have read it, in whole or in part, and that it has not changed on disk since, because otherwise the write would discard content you have not seen; creating a new file or appending needs no prior read. For a partial change to an existing file prefer Edit, which sends only the changed text. Content is written literally, so leave out Read's line-number prefixes.
