Find files by name pattern, most recently modified first. A pattern without `/`, such as `*.ts`, matches at any depth. A pattern with `/` is anchored at the search directory: `src/*.ts` matches one level and `src/**/*.ts` any depth. `*` alone lists only the files directly in the search directory. Results are files, never directories; to see a directory's entries, Read the directory. Without `path` the search starts at the working directory. Returned paths are either absolute or relative to the working directory, so they can be passed to Read unchanged. Files excluded by `.gitignore` are skipped unless `include_ignored=true`; `.git` and secret files are always left out. At most `head_limit` paths come back (default 100); when more exist, the result gives the `offset` that continues. Each call searches again, so results can shift between pages.
