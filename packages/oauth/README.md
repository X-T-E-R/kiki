# @kiki/oauth

OAuth and managed-authentication support for Kiki's Kimi sign-in, including the
account, quota, and credential-lifecycle calls the settings UI depends on.

This is a workspace package. It is marked `private: true`, so it is not
published to npm as its own release; the guidance here assumes a repository
checkout rather than an installed dependency.

To sign in or manage a provider as a user, use `/login` in the CLI or the
provider settings in the GUI. See the
[documentation site](https://x-t-e-r.github.io/kiki/en/) for the reader-facing
instructions.
