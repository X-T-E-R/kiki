Keep the SSH hosts you add to a conversation in one place above the input instead of repeating them on every message. The Session SSH control stays visible for as long as the host is joined, so you can see, add and remove hosts at any time, and each message you send now carries only what you typed and attached. Hosts chosen on a new session are joined to it before your first message is sent, and messages sent before this change still read as you typed them.
