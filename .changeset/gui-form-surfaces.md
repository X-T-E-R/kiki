Forms no longer appear as a block pushed into the page. Adding a connection, adding a notification channel, and adding or editing an MCP server now open in a side panel next to the list. A permission rule opens in a small dialog. Rows that edit their own values (models, catalog imports, goals, model prices) unfold under the row with a short transition. When no connection exists yet, the add flow is still the page itself.
