Settings drop the Runtime section — its options moved to Tasks, Advanced, and Agents — and model parameters can now be edited from both the model row and the provider editor, with provider ids containing characters like `:` saving correctly again. Dialogs adopt larger standard sizes, the global task board opens from inside the session rail and loads every workspace in one call, and the composer no longer double-sends while a send is in flight.
