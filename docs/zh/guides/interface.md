# 界面导览

桌面版和浏览器界面是同一套 UI，一个会话由三块组成：对话视图、输入框、右侧栏。本页就是这三块的导览；看板、草稿和恢复见[工作区与会话管理](/zh/guides/sessions)，同样的概念在终端里的操作见[交互与输入](/zh/guides/interaction)。

## 对话视图

这里是会话时间线：assistant 消息、工具调用、审批、提问和后台任务通知。

轮次结束却没有回复时，轮次尾部会说明后台仍在执行、当前没有执行中的工作，或执行状态未知。有**重新发送**按钮时，点击会把原消息文字放回输入框，不会自动发送。

来自其他 Agent 或会话的消息在正文上方显示来源标题；没有标题时，回退为任务名或短 ID。悬停可查看完整身份；点击可打开来源 Agent，或当前连接可访问的来源会话。复制或引用时只取正文，不重复来源标签；编辑时保留原始来源前缀。你自己输入的来源标签仍按原文显示。用户消息之后注入的上下文，在重新打开或继续加载对话后仍留在该消息之后。

已处理的内容——你回答过的提问、你批准过的请求、各种标记——会收成单行紧凑条目，留在它发生的位置。提问在等待回答和对话继续更新时都保留原位；展开条目可查看保存的问题与答案。连续多条会折叠成一行**活动历史**，点开即可展开。展开或收起对话条目时，界面会保留当前阅读位置；继续滚动后由你控制读位。失败和取消的条目始终单独显示。目标更新这类重复标记，在中间没有消息或工具调用时只显示最新一条并带上次数（例如「目标已更新 ×12」）。

子智能体的派遣卡默认展开这次运行期间新建的子智能体。其他运行留下的子智能体，或无法确认创建时间归属的条目，会收在**其他子智能体**一行里，显示数量以及运行中、失败的数量；点开仍能看到原来的子卡。续跑旧子智能体不会让它变成新建条目，后续状态变化也不会覆盖你手动展开或收起的选择。

文件引用可以预览、打开，或在所在文件夹中显示。重新打开会话或加载 Agent 的已保存历史时，每次模型切换都会显示一条分隔条，标出切换前后的模型；只调整思考力度不会多出分隔条。

点击图片会打开单层查看器，用前后按钮或 `←` / `→` 连续浏览这个 Agent 已加载对话里的图片。长图按宽度适配，可上下滚动；点击图片或使用尺寸按钮切换到原尺寸后，可以拖动平移。

在图片下方选择**标注图片**，即可进入**标注模式**。底部工具栏支持箭头、矩形、自由画笔、选择和撤销；**完成**会在查看器中保留标记，**取消**放弃本次编辑。右键或按 `Shift-F10` 可以复制、保存图片；带标注的图片可另存为 PNG，不改动原件。来源确有链接或路径时才显示相应操作，本机打开和文件夹定位仅对支持这些操作的本机文件提供。图片加载失败时，可以重试，也可以继续浏览下一张。

较长的工具输出和其他大字段分段加载。字段被截断时选**继续加载**可以取回其余部分，行上会告诉你已加载多少。续读在有原件可取的字段上失败时——工具的输入或输出、后台任务自己的输出——同一行会提供**下载原文**，把完整内容存到你的机器上，并显示保存中、已保存和重试状态。重试始终可用，但不是每个字段都能下载。

## 输入框

输入框接受自由文本：`Enter` 发送，`Shift-Enter` / `Ctrl-J` 插入换行。剪贴板里的图片和视频可以直接粘贴，前提是当前模型支持——细节见[交互与输入](/zh/guides/interaction)。

在已有会话中，修改**审批方式**、在**普通**与**计划**之间切换，或修改 Plan gate，都会立即保存，无需发送消息。使用原生执行器时，下一次工具审批按新权限模式判定，Plan 模式的限制作用于当前轮次后续的工具调用，gate 决定下一次计划提交是否需要审批。已经挂起的审批仍需你决定。保存失败时，控件会恢复为会话报告的设置并显示错误。

修改原生模型或思考力度也无需发送消息：当前请求继续完成，新绑定在下一次模型请求前生效。待切换提示会标出这次修改；准备开始前，可以展开队列取消。切换失败会保留当前绑定并显示错误。**默认**会清除手选力度，依次恢复 persona 固定力度、所选模型的 profile 默认力度、模型默认力度。切换 profile 或引擎仍随下一条消息应用。

`↑` 和 `↓` 在草稿内移动光标，自动折行时也一样。只有光标在文本起点时，`↑` 才浏览更早的输入；只有在文本终点时，`↓` 才浏览更近的一条。会话各自保留记录，新建会话页则按该工作区保留。有选区、按住 `Shift`、正在用输入法组字，或打开了 `/` 与 `@` 菜单时，这些键仍留给编辑。`Esc`，或在最新一条之后再按 `↓`，会恢复浏览前的草稿。

在对话中选中文字，再选**引用**，会把这段文字加入输入框上方。可以连续加入多段，也可以逐项移除。发送时会带上这些引用；等待发送确认期间新加的引用仍留在草稿里。输入 `@` 可查找工作区文件，选择**加载更多**或滚到匹配列表末尾可加载下一页。

输入框的 **+** 菜单可以把 SSH 主机加入会话。加入的主机属于这个会话，而不是每条消息都要带一遍，所以输入框上方的 **本会话 SSH** 只要有主机加入就一直在：它列出已加入的主机，点 **X** 移出，也可以从这一行重新打开主机列表增删。添加主机只是让会话能用上它，不会立刻连过去。全新会话中该控件显示为 **待加入 SSH**，你选中的主机会在第一条消息发出前加入。

同一个菜单的 **Session** 分组里有 **MCP 服务器 ▸**，它列出当前对话能看到的每一个 MCP 服务器：引擎报告的各自状态（已连接、正在连接、需要登录，或它给出的错误）、来源文件或 plugin，以及这个对话确实可以重试时的 **重新连接**。读这个列表不会发送任何内容，也不会动你的草稿。每一行旁边的开关把该服务器加入当前对话，或只从当前对话移出——配置和你的其他对话不受影响，这个选择在关闭面板后依然保留。第一条消息发出前，服务器选择先留在草稿中，再在消息开始前应用。plugin 自己关闭的服务器、或运行时名称属于另一个来源的服务器不会画开关，因为引擎会拒绝这次写入。服务器在 [MCP 页面](../server/mcp.md#配置)里按工作区配置。同一分组里的**重建上下文**会重新读取该 agent 的提示词来源，但不会新建对话——见[重建会话上下文](../customization/agents-and-subagents.md#重建会话上下文)。

Agent 忙碌时，你提交的新消息默认进入输入框上方的队列，而不是打断它。每条排队消息可以单独设定发送时机——**空闲后**、**子智能体完成后**、**任务完成后**——并在队列中对应的那一行上改时机、改文字、调顺序或立即发送。编辑时会恢复消息中的引用和原图预览，重启后也一样。**取消**会回到之前的草稿和选择；原图暂时不可用时，界面会报告原因，原排队消息保持不变。

同一队列里的定时提示词会显示 **定时任务** 标签和正文摘要。点击摘要可展开完整正文。定时提示词的正文在队列中只读；你提交的消息仍可编辑。在定时任务页上设为**排队**的任务保留调顺序和立即发送控件。

等待**空闲时插入**的定时提示词统一显示在队列最前面的一个区域中，各个任务的正文和**移除**操作都保留在该区域内。设为**立即插入**的提示词仍在自己的行上显示投递时机。这两种模式都不属于普通发送顺序，不计入普通消息的待发送条数，也不提供调顺序或立即发送控件。**移除**只取消这一次待投递的提示词；周期任务仍保留，下次到时仍可触发。

要为你提交的消息选时机，把鼠标悬停在发送按钮上，或聚焦后按 `↓`。除默认时机外，你可以把消息送进当前轮次、让 Agent 在下一个安全步骤读到它（默认发送快捷键下等同 `Ctrl-Enter`）、等子智能体结束后再开始，或等所有后台任务结束后再开始。选定后只作用于这一条消息。Agent 空闲时不显示这个菜单。

普通排队消息按队列顺序逐条运行，每条各自成为一个轮次；前一轮结束后，下一条才开始。使用原生执行器时，你显式送入当前轮次的消息仍可在同一个安全步骤合并成一块模型输入。Steering 和提交 hook 每批只触发一次；每条原消息仍保留各自的历史记录和结果。

切换 profile 或引擎需要独立轮次，即使选择**立即发送**也一样。送入当前轮次的消息如果执行设置不同，也不会合批。外部引擎按握手结果决定是否提供当前轮送入。AGY CLI 会在同一轮的下一次模型调用时送入消息；若该轮先结束，消息留在 Kiki 队列中等待下一轮。对所有外部引擎，Kiki 最多等待 60 秒让正在运行的工具调用结束再发送；超时则消息继续排队。投递结果未知时，队列会暂停；请先查看时间线，再决定是否继续队列。

当 main agent 正在前台等一个 `AgentRun` 时，**立即发送**会把这个等待转到后台而不终止子 Agent，子 Agent 完成时仍会自动回报；普通排队不会触发这个转移。

在 main agent 还没回复、也没调用工具时把它停掉，被打断的提示词连同附件会回到会话草稿里，和你尚未发送的编辑放在一起。Agent 已经回复过或已被 steering 的提示词不会回填；附件回填要求已加载的对话记录里保留了完整提示词，且回填的附件只存在于本次应用运行的内存中。

重启后，排队消息会回来等着你决定。单条消息上选立即发送，就只发这一条；**继续发送**释放整个队列。**稍后**只是收起说明——继续发送按钮仍然可见，你在此期间新提交的消息也会继续排队，直到你恢复队列。

原生 subagent 的**审批方式**与 **Plan** 控件会立即作用于这个 Agent，不影响其他 Agent，权限仍受其上限约束。外部 subagent 的这些模式由执行器管理，因此界面会显示原因，不提供这两个控件。

在 subagent 的输入框里，停止请求还没返回时停止按钮会暂时禁用；请求失败会给出原因提示，按钮恢复后可重试。停掉一次运行不会动这个 subagent 队列里的其他消息。

## 审批

受保护的操作执行前会在时间线里显示审批请求，你可以只批准这一次，或批准整个会话。默认的 Auto 模式下普通工具调用直接执行，敏感文件和指向工作区外的链接仍要审批。manual 模式会先问 Shell 命令和工作区外的写入，受信任目录内的 `Write` / `Edit` 不再逐项询问。YOLO 模式跳过敏感文件询问，但显式 deny 规则依然优先。按 `Esc` 中断的工具调用会在执行前停下。

## 右侧栏

右栏一次只描述一个 Agent：你最后点进去或聚焦的那个。main agent 和每个 subagent 用的是同一套页面，进到 subagent 的记录里，右栏也跟着你走。它显示这个 Agent 此刻在做什么、等着你处理的条目、活动流，以及两个可独立折叠的能力区块。

使用原生执行器时，上下文概览采用所选 Agent 当前有效的模型上限，并保留已绑定 profile 和 recipe 的约束。修改该模型的配置上限后，已打开的 main 和 subagent 视图会更新窗口、占比和自动压缩点。无法取得上限时仍显示 token 数，但不显示占比；历史轮次记录的用量保持原值。

Agent 树会在名称旁标出外部执行器；只有明确选择过 **off** 时，思考力度才会显示这个值。

**能力清单**分为**工具**、**技能**和**子智能体**三个页签；工具列表也包含插件与 MCP 提供的工具。子智能体的每一行写出 profile 与 route，以及现在能否启动。要改这个智能体能创建谁，见[派遣能力](./settings.md#派遣能力)。

**能力控制**集中放置当前对话的插件使用、系统能力开关与 MCP 服务器选择，与能力清单分开。开启**浏览器**会在当前工具策略允许的范围内开放浏览器工具；浏览器设置会显示可用连接及连接失败的原因。Ego Lite 使用原生 `browser__ego_run` 工具，不另列一套按操作拆分的页面工具。

**IM 对话**只列出绑定到当前对话的信道，每条绑定有独立开关。同一账号下的不同信道（包括 Telegram topic）可以分别绑定不同对话；无关账号的重连状态不会出现在这里。有入站信道等待确认时，可选**绑定到此会话**明确建立绑定。

桌面宽度下右栏默认展开。页头的 **Standard / Cockpit** 让它临时加宽、占用预览区，对话和输入框仍留在主列；选 **Standard** 或 **退出驾驶舱**会把原来的预览内容、页签、草稿和宽度还原。

文件栏可以预览工作区文件和会话附件。图片按原分辨率打开，也可以从对话中点击放大；名称优先使用真实文件名，没有文件名时显示**图片**。MP3、WAV、OGG、M4A、FLAC、AAC 和 Opus 使用内置音频播放器；浏览器无法解码时仍可下载原文件。

Markdown 和 HTML 文件在预览区提供**渲染 / 源码**切换。HTML 预览在独立的文档沙箱中保留脚本运行、样式、嵌入字体、相对资源和本地存储能力，无法访问 Kiki 凭据、父界面或桌面桥。HTML 渲染需要与服务器建立本地连接，并指定包含文档的资源根目录；无法获得访问权限时，可查看**源码**或下载文件。

PDF 在本地渲染，包含中文和嵌入字体，无需另装渲染程序；翻页时保留已打开的 PDF，不再重新下载。DOCX、XLSX、PPTX 使用 Office 插件的 OfficeCLI 渲染。Word 和演示文稿可以翻页，Excel 可以选择工作表。

Office 尚未安装时，可在预览中查看安装计划并同意安装；这只安装 Office 插件及其渲染程序，不安装整套 Work 插件。若你曾停用 Office，**启用 Office 预览**会明确说明这次启用；已启用但只缺 OfficeCLI 时，则只提供渲染程序的安装入口。文本与 CSV 预览明确标为源文本，只加载了一部分时可以续读。文档的渲染预览不会回写文件；支持桌面编辑时，源码编辑器保留原有的保存控件。

旧格式 `.doc`、`.xls`、`.ppt` 及 OpenDocument 的 `.odt`、`.ods`、`.odp` 暂无已接入的页面渲染器。请选择**下载原文件**或在本机打开原件，不要把提取的文字当作原页面排版。预览失败时可以重试，源文件保持不变。

## 会话与工作区

会话列表按工作区分组，选一个恢复，或在那里新建草稿。按工作区查看时，工作区标题上的加号会在该工作区新建草稿。哪些标题有这个加号、它不会改动什么，见[启动与恢复会话](/zh/guides/sessions#启动与恢复会话)。已保存但已不可用的模型、配置档案（profile）或思考力度会带着诊断信息继续显示，等你选一个有效值，界面不会悄悄换成别的模型。其余见[工作区与会话管理](/zh/guides/sessions)。

列表上方是侧栏自己的入口。记忆、角色、用量默认直接显示；任务看板、定时任务、能力和**发现 Kiki**默认收在**更多工具**下面，就地展开，并记住你有没有把它展开。**设置 → 常规 → 侧栏常用工具**决定哪些入口保持可见，同一份列表也在列表顶部的视图选项菜单里。已保存的选择保持不变。
