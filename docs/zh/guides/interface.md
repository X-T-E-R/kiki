# 界面导览

桌面版和浏览器界面是同一套 UI，一个会话由三块组成：对话视图、输入框、右侧栏。本页就是这三块的导览；看板、草稿和恢复见[工作区与会话管理](/zh/guides/sessions)，同样的概念在终端里的操作见[交互与输入](/zh/guides/interaction)。

## 对话视图

这里是会话时间线：assistant 消息、工具调用、审批、提问和后台任务通知。

已处理的内容——你回答过的提问、你批准过的请求、各种标记——会收成单行紧凑条目，留在它发生的位置。连续多条会折叠成一行**活动历史**，点开即可展开；失败和取消的条目始终单独显示。目标更新这类重复标记，在中间没有消息或工具调用时只显示最新一条并带上次数（例如「目标已更新 ×12」）。

子智能体的派遣卡默认展开这次运行期间新建的子智能体。其他运行留下的子智能体，或无法确认创建时间归属的条目，会收在**其他子智能体**一行里，显示数量以及运行中、失败的数量；点开仍能看到原来的子卡。续跑旧子智能体不会让它变成新建条目，后续状态变化也不会覆盖你手动展开或收起的选择。

文件引用可以预览、打开，或在所在文件夹中显示。重新打开会话或加载 Agent 的已保存历史时，每次模型切换都会显示一条分隔条，标出切换前后的模型；只调整思考力度不会多出分隔条。

较长的工具输出和其他大字段分段加载。字段被截断时选**继续加载**可以取回其余部分，行上会告诉你已加载多少。续读在有原件可取的字段上失败时——工具的输入或输出、后台任务自己的输出——同一行会提供**下载原文**，把完整内容存到你的机器上，并显示保存中、已保存和重试状态。重试始终可用，但不是每个字段都能下载。

## 输入框

输入框接受自由文本：`Enter` 发送，`Shift-Enter` / `Ctrl-J` 插入换行。输入框为空时按 `↑` / `↓` 浏览在当前工作目录输入过的内容。剪贴板里的图片和视频可以直接粘贴，前提是当前模型支持——细节见[交互与输入](/zh/guides/interaction)。

输入框的 **+** 菜单可以把 SSH 主机加入会话。加入的主机属于这个会话，而不是每条消息都要带一遍，所以输入框上方的 **本会话 SSH** 只要有主机加入就一直在：它列出已加入的主机，点 **X** 移出，也可以从这一行重新打开主机列表增删。添加主机只是让会话能用上它，不会立刻连过去。全新会话中该控件显示为 **待加入 SSH**，你选中的主机会在第一条消息发出前加入。

同一个菜单的 **Session** 分组里有 **MCP 服务器 ▸**，它列出当前对话能看到的每一个 MCP 服务器：引擎报告的各自状态（已连接、正在连接、需要登录，或它给出的错误）、来源文件或 plugin，以及这个对话确实可以重试时的 **重新连接**。读这个列表不会发送任何内容，也不会动你的草稿。每一行旁边的开关把该服务器加入当前对话，或只从当前对话移出——配置和你的其他对话不受影响，这个选择在关闭面板后依然保留。plugin 自己关闭的服务器、或运行时名称属于另一个来源的服务器不会画开关，因为引擎会拒绝这次写入。服务器在 [MCP 页面](../server/mcp.md#配置)里按工作区配置。同一分组里的**重建上下文**会重新读取该 agent 的提示词来源，但不会新建对话——见[重建会话上下文](../customization/agents.md#重建会话上下文)。

Agent 忙碌时，你提交的新消息默认进入输入框上方的队列，而不是打断它。每条排队消息可以单独设定发送时机——**空闲后**、**子智能体完成后**、**任务完成后**——并在队列中对应的那一行上改时机、改文字、调顺序或立即发送。

同一队列里的定时提示词会显示 **定时任务** 标签和正文摘要。点击摘要可展开完整正文。定时提示词的正文在队列中只读；你提交的消息仍可编辑。在定时任务页上设为**排队**的任务保留调顺序和立即发送控件。

等待**空闲时插入**的定时提示词统一显示在队列最前面的一个区域中，各个任务的正文和**移除**操作都保留在该区域内。设为**立即插入**的提示词仍在自己的行上显示投递时机。这两种模式都不属于普通发送顺序，不计入普通消息的待发送条数，也不提供调顺序或立即发送控件。**移除**只取消这一次待投递的提示词；周期任务仍保留，下次到时仍可触发。

要为你提交的消息选时机，把鼠标悬停在发送按钮上，或聚焦后按 `↓`。除默认时机外，你可以把消息送进当前轮次、让 Agent 在下一个安全步骤读到它（等同 `Ctrl-Enter`）、等子智能体结束后再开始，或等所有后台任务结束后再开始。当 main agent 正在前台等一个 `AgentRun` 时，**Send now** 会把这个等待转到后台而不终止子 Agent，子 Agent 完成时仍会自动回报；普通排队不会触发这个转移。选定后只作用于这一条消息。Agent 空闲时不显示这个菜单。

在 main agent 还没回复、也没调用工具时把它停掉，被打断的提示词连同附件会回到会话草稿里，和你尚未发送的编辑放在一起。Agent 已经回复过或已被 steering 的提示词不会回填；附件回填要求已加载的对话记录里保留了完整提示词，且回填的附件只存在于本次应用运行的内存中。

重启后，排队消息会回来等着你决定。单条消息上选立即发送，就只发这一条；**继续发送**释放整个队列。**稍后**只是收起说明——继续发送按钮仍然可见，你在此期间新提交的消息也会继续排队，直到你恢复队列。

在 subagent 的输入框里，停止请求还没返回时停止按钮会暂时禁用；请求失败会给出原因提示，按钮恢复后可重试。停掉一次运行不会动这个 subagent 队列里的其他消息。

## 审批

受保护的操作执行前会在时间线里显示审批请求，你可以只批准这一次，或批准整个会话。默认的 Auto 模式下普通工具调用直接执行，敏感文件和指向工作区外的链接仍要审批。manual 模式会先问 Shell 命令和工作区外的写入，受信任目录内的 `Write` / `Edit` 不再逐项询问。YOLO 模式跳过敏感文件询问，但显式 deny 规则依然优先。按 `Esc` 中断的工具调用会在执行前停下。

## 右侧栏

右栏一次只描述一个 Agent：你最后点进去或聚焦的那个。main agent 和每个 subagent 用的是同一套页面，进到 subagent 的记录里，右栏也跟着你走。它显示这个 Agent 此刻在做什么、等着你处理的条目（可以直接在行上做决定）、活动流，以及一个折起来的能力区块。**Dispatch capabilities** 打开的是 Agent 派发 subagent 的配置面板，从那里可以看到某个 subagent 的配置档案（profile）、路由和执行器，以及它的默认模型与思考力度（effort，模型投入多少推理）来自哪里——见 [Agent 与 subagent](../customization/agents.md#重建会话上下文)。

桌面宽度下右栏默认展开。页头的 **Standard / Cockpit** 让它临时加宽、占用预览区，对话和输入框仍留在主列；选 **Standard** 或 **退出驾驶舱**会把原来的预览内容、页签、草稿和宽度还原。

文件栏为工作区文件和会话附件提供只读文档预览。PDF 在本地渲染，包含中文和嵌入字体，无需另装渲染程序。DOCX、XLSX、PPTX 使用 Office 插件的 OfficeCLI 渲染。Word 和演示文稿可以翻页，Excel 可以选择工作表。

Office 尚未安装时，可在预览中查看安装计划并同意安装；这只安装 Office 插件及其渲染程序，不安装整套 Work 插件。若你曾停用 Office，**启用 Office 预览**会明确说明这次启用；已启用但只缺 OfficeCLI 时，则只提供渲染程序的安装入口。文本与 CSV 预览明确标为源文本，只加载了一部分时可以续读。预览不会回写文档。

旧格式 `.doc`、`.xls`、`.ppt` 及 OpenDocument 的 `.odt`、`.ods`、`.odp` 暂无已接入的页面渲染器。请选择**下载原文件**或在本机打开原件，不要把提取的文字当作原页面排版。预览失败时可以重试，源文件保持不变。

## 会话与工作区

会话列表按工作区分组，选一个恢复，或在那里新建草稿。已保存但已不可用的模型、配置档案（profile）或思考力度会带着诊断信息继续显示，等你选一个有效值，界面不会悄悄换成别的模型。其余见[工作区与会话管理](/zh/guides/sessions)。
