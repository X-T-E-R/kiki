# 记忆

记忆是会话留不住的东西。Kiki 把你的偏好、反馈、已核实的项目事实和参考指引存下来，在之后的对话里再找回来。它默认开启，只存在运行 Kiki 的那台机器上，每次写入都会在对话里留下一行。这一页讲 **/memory** 页提供的选择、可能挡在智能体和写入之间的审批收件箱，以及怎么把记忆关掉。

如果你想看的是智能体在**单个会话内**能做什么——压缩、队列、任务看板——请看[长时间的活](/zh/features/long-work)。

## 智能体记住什么

记忆不是对话记录，也不是缓存。它是那一点点你不希望每次重新解释的长期事实：你的代码希望怎么被审、上周核实过的哪个项目事实、参考资料在哪。任务进展属于智能体的工作笔记，不属于这里。

智能体用 `MemoryWrite` 写记忆，用 `MemorySearch` 和 `MemoryRead` 读回来。搜索支持部分词命中，也支持不加空格的中文短语。原生 subagent 默认就能用只读的 `MemorySearch` 和 `MemoryRead`；`MemoryWrite` 始终只给主智能体。

主智能体的 `TodoList` 笔记可以在 `directives` 和 `decided` 里用条目 id 引用记忆，比如 `[m_id]`。压缩时，交接文本会带上每条被引用记忆的当前标题、跟随替代条目，并把已归档的条目标为已撤回。解析这些引用不会改写保存的笔记或冻结的系统提示词。

## 这一页让你选什么

在 **/memory** 页上，你选的是「正在看哪一部分记忆」，而这一页始终提供同样的三个选择：

- **全局（Global）**——所有项目共享。
- **工作区（Workspace）**——单个项目的存储。
- **角色（Persona）**——某个角色自己的存储，跟着这个角色跨 profile 和模型。

角色专属条目与其他角色隔离。默认情况下角色也能读共享的全局和工作区记忆；在角色卡上设 `memory.shared: []` 可以排除。工作区有自己的开关，可以跟随全局、单独开启或单独关闭。在某个工作区关掉记忆，已保存的条目仍然留在那里——只是智能体在那里不再读也不写。

这是这一页提供的选择，不等于「所有东西都只有三种存法」：角色除了整体记忆，还有按工作区分开的那一部分，所以一个跨项目的角色可以自己再记项目相关的事。

### 角色

角色的记忆跟着身份而不是跟着项目。它会跟着这个角色跨 profile 和模型，所以换模型不会弄丢它知道的事。删除角色也会删掉它的角色记忆；如果清理失败，删除操作会报告错误并保留角色卡，方便重试。见[角色、Bot 与房间](/zh/customization/personas#记忆与角色卡)。

条目是有类型的，类型就是你要筛选的维度：**关于你**、**反馈**、**项目**、**参考**。条目还可以是**置顶**（排在最前）、**生效中**、**被更新条目替代**，或**已归档**。

## /memory 页

侧栏里 **/memory** 是常驻入口，无论记忆开着还是关着都在——关着的时候它是「怎么打开」的说明页，开着的时候它是管理台。你可以搜索条目、按类型筛选、显示或隐藏已归档的条目，点开一条就能读、改、置顶或删除。

工作区和角色都是可搜索的选择，因为任何一个列表都可能有几百项；选了一个会清掉另一个，选择会带在 `?workspace=` 或 `?persona=` 参数上，所以指向某个范围的链接仍然有效。

### 改动历史与撤销

对条目的每一次改动都会留下记录，每条历史行打开后能看到改动前后内容，并提供针对这一次操作的**撤销**——删除也一样。所以删除确认框说的是「你可以撤销」，而不是声称删了就没了。

如果你打开着这条的时候它被别人改了，保存会被拒绝并提示先重新加载，这样你的修改不会盖掉更新版本。重新加载条目，再改一次。

## 审批收件箱

记忆审批有三种设置。默认的**自动**会把智能体提议的写入直接应用；改成**审查**，提议的更新或归档就会先等你处理。在**自动**下没有任何待处理内容，所以不会出现**收件箱**页签。

提议等待期间，原条目保持当前内容并继续生效。**保留**表示应用这条提议——更新会替换它所替代条目的正文，归档会归档那个条目。**丢弃**只去掉这条提议，原条目不动。

## 关掉记忆

**/memory** 页上有一个**使用记忆**开关，桌面版设置里也是同一处。关掉之后，智能体不再读写记忆。定期的长时记忆提醒是另一回事：只想停掉这些提醒、同时保留「新指令」和「压缩前」检查，在 `config.toml` 里设 `memory_maintenance = false`。它不会关掉记忆工具、审批或任务笔记——见[连续性提醒设置](/zh/configuration/config-files#连续性提醒设置)。
