# 设置页导览

Kiki 桌面版在**设置**对话框里提供偏好设置，在侧栏的「用量」等独立页面展示活动。本页帮你定位各项控制、了解它会改变什么；完整参考见各节链接。

设置侧栏把 20 个入口分在七个分组里：**应用**、**模型与智能体**、**会话与工作**、**能力**、**权限与规则**、**连接与远程**、**高级**。其中四个入口由原来的多页合并而来，用标签页切换——**模型与提供商**、**智能体**、**扩展与工具**、**浏览器与电脑**——所以下文路径末尾写的标签名，是在该入口里再点一步。

**「我想改 X」速查表：**

| 我想改… | 去哪里 |
| --- | --- |
| 用订阅账号登录，或添加 API 密钥 | **模型与智能体 → 模型与提供商 → 服务与账号** |
| 对外请求怎样表明自己的身份 | **模型与智能体 → 模型与提供商 → 身份** |
| 版本与更新通道（Stable / Beta） | **高级 → 关于与更新** |
| Agent 配置档案、提示词覆写 | **模型与智能体 → 智能体 → 智能体配置** |
| 长期记忆的低频维护提醒 | `config.toml` 的 [`loop_control.continuity_cadence.memory_maintenance`](../configuration/config-files.md#连续性提醒设置) |
| 输入框草稿是否记住 | **应用 → 常规** |
| 把选定设置迁移到另一个 Home 或设备 | **应用 → 常规 → 设置迁移** |
| 后台任务上限与定时任务 | **会话与工作 → 会话** |
| 搜索与抓取的配置来源 | **能力 → 搜索与抓取** |
| 已安装的插件、技能与 MCP 服务器 | **能力 → 扩展与工具** |
| subagent 派发配置 | **模型与智能体 → 智能体 → 子智能体与派发**（全服务默认值）；单个配置档案的**子智能体**在**智能体配置**标签 |
| 为 Agent 任务运行浏览器 | **能力 → 浏览器与电脑 → 浏览器控制** |
| 控制服务机自己的桌面 | **能力 → 浏览器与电脑 → 电脑控制** |
| 实验性功能 | **高级 → 开发与实验**，页面底部的**实验功能入口** |
| 查看当前会话的提示词来源 | 会话标题栏 **⋯ → 提示词生效详情** |
| 暂时用预览区域显示驾驶舱 | 右侧面板标题栏**驾驶舱** |
| Token 用量与费用 | **用量 → 历史（Usage → History）** |
| 正在运行或排队的模型请求 | **用量 → 实时（Usage → Live）** |
| 模型／供应商请求并发 | **用量 → 实时 → 并发限制（Usage → Live → Concurrency limits）** |
| 把用量发送到其他服务 | **用量 → 外部同步（Usage → External sync）** |
| TUI 主题、编辑器等 CLI 侧偏好 | 终端里的 `/config` 等命令，见 [CLI 侧对应](#cli-侧对应) |

## 导入与导出设置

打开**设置 → 应用 → 常规 → 设置迁移**，再点**导入或导出**。导出时可同时勾选多个类别，并查看项目数：模型与提供商、智能体与提示词、权限与会话、工具／MCP／插件、浏览器与电脑、通知／IM、外观与设备。**包含凭证**默认不勾选；只有下载的 JSON 文件会保持私密时才开启，文件中保存的是真实已存凭证，不是脱敏占位符。外部账号登录不会迁移。

在目标端选择**导入**，打开不超过 8 MiB 的 `kiki.settings` JSON 文件。核对目标 Home 和空间，勾选类别，再查看新增、冲突与跳过数量。默认的**保留现有值**保留已有 ID、配置键和资源，包括显式继承的限制。**替换选定值**只替换所选类别中设置包实际携带的键和资源，其他内容保持原样。不导入凭证时，目标已有的凭证也会保留。点**取消**不会写入。

设置包包含源 Home 的显式设置、格式有效的用户 Profile 与 `SYSTEM.md`、引用的提示词 TOML 文件、用户级 MCP 定义，以及已保存的设备偏好。不复制继承默认值、项目或系统通用 Profile 目录、聊天记录、缓存、已安装的插件／Recipe 包或皮肤资源。请另行安装所需组件，并在目标端核对本机路径与命令。引用的提示词文件缺失或无法安全迁移时，会拒绝导出或应用设置包。

勾选**包含凭证**时，还会迁移在 Kiki 中保存的搜索 API 密钥，并核对其提供商、凭证槽与服务地址绑定。设置中的环境变量名称会保留，但不会复制进程环境变量的值或其他应用登录、凭证文件中的密钥。未勾选凭证时，会略过在参数中直接携带请求头或令牌的 MCP 定义。

点**应用**后，Kiki 读回保存值并逐项报告变更状态。部分完成表示已有项目保存成功；请核对状态，重新预览后再重试。配置保存后会重载。Profile 变更和仅适用于新会话的设置在新会话中生效；已有对话在[重建上下文](../customization/agents-and-subagents.md#重建会话上下文)前仍保留绑定的提示词来源。

## 连接

**设置 → 模型与智能体 → 模型与提供商**打开默认的**服务与账号**标签（`/settings/ai?tab=providers`）；旁边是**默认值**（`/settings/ai?tab=defaults`）和**身份**（`/settings/ai?tab=identity`）。`/settings/providers` 和 `/settings/models` 都会打开同一标签。这一页按这个顺序分成三个区，底部另有折叠的**维护**区。

**① API Key 服务商**列出用密钥接入的在线 API。这一区的列表是空的，并不表示整页没有连接。

**添加连接**用来加入用密钥接入的服务。还没有任何连接时，表单就是这一页；已有连接时，它在各列表旁边打开。它会问接哪个服务、用什么方式：

- **从目录选**：从 models.dev 选一个服务，Kiki 填好地址和模型列表。若该 id 已存在，则更新那个连接，表单会在提交前说明。
- **自己填写**：协议、地址和密钥，适用于目录里没有的服务，包括本机服务器。

无论哪条路径，都要在连接表单里用**添加模型**，再点**保存提供商**。只要存在连接，搜索就覆盖全部已配置的连接，也会按模型的 ID 和名称找到所属连接。新的连接出现在与接入方式对应的那一区。

**② 账号登录（订阅直连）**列出已经连上的订阅账号：Kimi Code、用于 Codex 的 ChatGPT 账号、Grok Build 账号、GitHub Copilot。还没连上的账号在这里点**登录**。已经有连接的账号不会再次出现；失效的登录在它自己的那一行恢复。

**③ 本机 HTTP 与 CLI**包括本机上的服务器，以及 AGY CLI、Codex、Claude Code 这类本机程序。CLI 程序启用后，在对话的运行方式里选择。**让外部客户端使用 Kiki** 打开**连接与远程 → 外部接入 → 智能体与客户端**（`/settings/connection-services?tab=clients`）。`/settings/external-clients` 打开同一标签。**浏览器**标签放 Web 访问与 Cloudflare 隧道；**其他 Kiki** 标签放允许连接你的 Kiki。

账号连接由登录写入，因此它的行里没有协议、地址或密钥可填。展开可看背后是哪个账号、服务方说还剩多少，以及改变登录的那一个操作：

- **已连接**：凭据可用，Kiki 会自行续期。**退出**只结束 Kiki 内的这次登录，并移除它带来的模型；不会退出该服务方的账号，也不影响服务方保存的账号信息。
- **登录已失效**：服务方已不再接受这次登录。**重新登录**在同一个连接上换掉它，列表里不会多出一行。
- **登录未完成**：流程结束但没有拿到凭据——你拒绝了、验证码过期，或中途失败。一行说明是哪一种，连接保持服务端如实报告的样子，不会留下半成品。
- **等待你确认**：登录正在进行，显示验证码、**打开验证页**、有效剩余时间，以及**取消登录**。

登录完成后，该账号的模型由服务端加入目录。在**服务与账号**中展开连接行，就能看到它的**模型**列表和登录状态。

在 Kiki 中退出只影响 Kiki。服务方保留你自己的订阅记录，重新登录会连回同一个账号。

### 复用本机已有的登录

对 ChatGPT（Codex）和 Grok Build，连接可以直接使用它们自己的 app 在本机已有的登录，而不必新建一个。Kiki 会复用它，并在它过期前主动续期；Kiki 不会复制凭据，也不会启动那个 app，在这里登录或退出都不会改变它那边的任何东西。

"本机"指 Kiki **服务端**所在的机器。通常就是你正在看的这台；当它不是时，**到服务端的其它目录中查找**可以指定要读取的目录。

**检测本机**会报告另一侧是哪个账号、凭据保存在哪里（文件、系统钥匙串或加密存储），随后出现的**使用这个登录**只接入刚报告的那个账号。期间被换掉的凭据会被拒绝，临近过期的凭据则直接使用并由 Kiki 续期。

当本机的凭据无法使用时，页面会给出你能据此行动的原因：没有该服务的账号、已退出、存放在读不到的位置，或属于另一个账号——并且不提供任何接入动作。

**停止使用**会放弃这个连接对本机登录的使用。它移除 Kiki 的引用和由此写入的模型；登录本身仍然保留在原处，另一个 app 不受影响。

### 超时

打开**设置 → 连接与远程 → 服务器连接**，在**当前连接**里找到 **HTTP 请求**（`/settings/connection?tab=current`）。这里控制本界面向 Kiki 服务端发起的请求，不是上面的提供商连接：

- **请求超时（秒）**——本界面向 Kiki 服务端发起的普通请求的默认截止时间。
- **阅读超时（秒）**——读取会话历史或正文时，最多等待多久才放弃。默认值为 `0`，即不设总截止：会话再大、加载再慢也一直等。如果你更希望卡住的读取尽快失败，就设一个秒数。

阅读超时只约束「等多久」，不限制「能读多少」。改动后的值对**下一次**读取生效——不会中断已经在跑的读取，也不会触发重连。除非你确实想要一个上限，否则保持 `0`。这两项是界面设置，不是 `config.toml` 里的键；决定多少历史留在服务端内存里的是另一套预算，见 [`transcript_memory`](../configuration/config-files.md#transcript-memory)。

## 模型与 Recipe

**设置 → 模型与智能体 → 模型与提供商**打开**服务与账号**。要编辑模型，展开它所在的连接行，打开**模型**列表并点击模型；完整编辑器会在侧面板打开。**默认值**（`/settings/ai?tab=defaults`）用来设置其它任务所用的模型。**身份**（`/settings/ai?tab=identity`）决定对外请求怎样表明自己的身份。`/settings/ai?tab=models` 和 `/settings/models` 会打开**服务与账号**；`/settings/ai?tab=providers&model=<model id>` 会直接打开该模型的编辑器。

标签上方的**新会话使用**栏和模型行上的星标都会设置新会话使用的全局默认模型。点旁边的标题、快速模型或 subagent，到**默认值**里修改。

在**服务与账号 → 决策服务**中，可添加 Jev、兼容 System One 服务或重排器，复用现有连接凭证。这些服务填写远端模型名即可，无需创建对话模型。在**默认值 → 谁来做判断**中，为权限审查和记忆顾问分别选择决策连接或已有对话模型。连接保存协议、端点和密钥；每项功能可覆盖远端模型名。配对打分服务只供记忆排序使用。见[决策连接](../configuration/providers.md#决策连接)。

在模型编辑器中修改请求设置与提示词正文，最后点一次**保存**。身份选择器分别保留**共用**、**主 Agent** 与**委托 Agent**的草稿；保存会带上三个身份里已做的修改。高级字段编辑的也是同一个模型，不是另一份表单。编辑从文件载入的正文会在模型上保存内联副本，原文件不变。**移除模型**在编辑器底部，点击后需要确认。

打开提示词本身不会离开共享组。**主 Agent**或**委托 Agent**仍沿用该组时，第一次**保存**提示词会把当时生效的整组复制到该身份上，未改的文件引用和节奏一并保留。此后再改共享组，不再影响这个身份。某个 steering 来源设为**沿用用户消息的设置**时，用的是当前选中身份上、用户消息已经在用的 steering 正文和节奏。这是已保存的 steering，不是用户消息的原文。身份保存成自己的提示词之后，沿用的就是这份身份上的 steering。未配置的来源保持关闭。

身份上的用量字段不是这种整组复制。改**默认思考强度**、**服务等级**、**最大生成 token**、**自动压缩触发点**或**上下文使用预算**时，只写那一项。共享的**上下文使用预算**或**最大生成 token**已经设置时，身份上更高的值不会抬高它，更低的值会收紧。**默认思考强度**、**服务等级**和**自动压缩触发点**按该身份上的值覆盖。**恢复使用共用值**会交还这一项；这次保存没带上的字段保持原样。

**切换模型**在该页的**默认值**（`/settings/ai?tab=defaults`）。它设置默认方式，以及**切换前询问**。**直接切换**保留当前上下文，**压缩后切换**先生成摘要，**全新上下文**开始新窗口。例外规则按 canonical 模型 ID 匹配。只有 `*` 和 `?` 是通配符，某一侧留空表示任意模型，第一条启用且命中的规则生效。**保存规则**替换这份列表，不改默认方式和询问设置。字段见 [`[model_switch]`](../configuration/config-files.md#model-switch)。

[Recipe](../customization/prompt-fields.md#recipe-模型配方) 提供一组可复用的提示词与模型设置覆盖。在模型编辑器中点**选择 Recipe**，可浏览已安装包、已配置市场或**导入**。先预览 URL 或服务端的绝对路径；HTTPS ZIP 还需要 SHA-256 校验值。查看或选中包不会应用它。

- **应用到模型**将所选 Recipe 与模型当前未保存的修改一起保存。**恢复手动设置**移除该模型的 Recipe 引用，也会保存这些修改；原有手动值与 profile 的独立 Recipe 都保留。
- **安装并应用**安装预览包，再执行同一次模型保存。**仅安装**只存包，不应用，也不保存模型草稿。应用失败时保留安装、选择与草稿；修正所报问题后重试**应用到模型**，无需重新安装。
- **复制并编辑**创建独立的本地 Recipe；**基于此继承**保留父源引用。在作者页的**提示词正文**或**源文件**中编辑，再点**保存 Recipe**。这只保存包，不替模型重新选择配方。混合的内联正文与文件正文按片段分别编辑。提示词修改若会重整 manifest 的 TOML 排版，页面会先提示；只改文件正文不会改写 manifest。
- **下载 ZIP**分享已接受的包及继承内容，不上传任何东西；先保存作者草稿。Profile 也可通过 [Markdown Frontmatter](../customization/prompt-fields.md#recipe-模型配方) 引用已安装的 Recipe。

Recipe 只覆盖自己声明的字段或提示槽，未覆盖的设置保留下层值，profile 的显式差异仍参与生效。正在运行的会话保留绑定时的版本；空闲后用[重建上下文](../customization/agents-and-subagents.md#重建会话上下文)采用当前来源。

**身份**标签是请求身份的集中页面：全局默认、内置与自定义身份、客户端版本、各身份的使用位置，以及最近的请求。供应商或单个模型在各自编辑器的**请求身份**一节携带自己的身份，靠后的层覆盖靠前的层。旧地址 `/settings/identity` 打开这个标签。见[在哪里配置](../configuration/providers.md#在哪里配置)。

## 关于与更新

**设置 → 高级 → 关于与更新**（`/settings/about`）显示当前版本，更新设置都在这里。**更新通道**选择 Stable 或 Beta，自动检查和手动检查都按这里的通道走。**自动检查更新**开关控制每天那次检查，关掉之后就只有点**检查更新**才会检查。**发现新版本时**决定那时怎么做：**通知我**弹出对话框，显示版本号和一小段变更摘要并等你决定；**下载并安装**则自己开始安装，不走那个对话框。两种模式都会在关闭还有运行中任务的空间之前先问你。

对话框的三个选择会被记住，不会每次重来：**明天再提醒我** 24 小时后再问，**跳过此版本**只让该通道的这个版本安静下来，两个方式下更新的版本都还会提示。安装前 Kiki 会重新核一遍通道和版本，底下已经变了的更新提议会被拒绝。某个选择没能保存时，对话框会留在原地请你重试。见 [Kiki 桌面版](../getting-started/desktop-app.md#更新)。

## 记忆

**设置 → 记忆**（`/settings/memory`）将总的**允许使用记忆**开关与**记忆顾问**分开。顾问卡显示来源，并链接到**默认值 → 谁来做判断**修改。选好来源、开启顾问即可使用，也可用示例数据测试已保存的来源；**高级**折叠区提供选择与请求预算及诊断。记忆页标题栏和 `Ctrl-K` 提供同一全局顾问开关，关闭时保留配置，恢复此前的记忆选择与正文。配置步骤见[记忆顾问](./memory.md#记忆顾问)。

## 智能体

**设置 → 模型与智能体 → 智能体**有两个标签。默认的**智能体配置**（`/settings/agents?tab=profiles`）把所选工作区的主 Agent 与 subagent 配置档案列成一张表——角色、引擎、模型、思考强度，以及谁能派发谁——并标出每份档案来自哪个文件。打开一行即可编辑它的指示与设置；文件型 profile 也可以在其显示的来源处直接编辑。同一标签里还有**身份与智能体加载**和**提示词字段**：后者编辑 `config.toml` 中的 `[prompt]` 提示词字段覆写段，卡片默认折叠，编辑前先展开。**子智能体与派发**（`/settings/agents?tab=dispatch`）放的是对所有配置档案生效的默认值——见[派遣能力](#派遣能力)。另见 [Agent 与 subagent](../customization/agents-and-subagents.md#派遣能力可见性) 和[提示词字段与覆写](../customization/prompt-fields.md)。

长期记忆维护提醒按自己的周期运行。若只想停掉这些提醒、保留新的持续指示和压缩前检查，在 `config.toml` 中设置 `memory_maintenance = false`；记忆工具、审批和任务笔记照常可用。见[连续性提醒设置](../configuration/config-files.md#连续性提醒设置)。

## 通知与消息

**设置 → 应用 → 通知与消息**（`/settings/notifications`）是设置侧栏里自己的一项。这里有三个标签：**通道与账号**（`/settings/notifications?tab=accounts`）、**何时通知**（`/settings/notifications?tab=rules`）和**本机**（`/settings/notifications?tab=device`）。旧的 `?tab=im` 和 `?tab=channels` 会打开**通道与账号**，`?tab=away` 会打开**本机**。

**通道与账号**有 **IM 账号与渠道**卡片，用来管理 QQ、Telegram 和微信等双向 IM 账号；另有**推送通道**卡片，列出单向 bot 和 webhook，并提供**选择内置通道**。QQ 的**配置账号**入口打开 kiki-qq 插件设置。QQ 0.4.0 同时提供手机 QQ 扫码、手填凭据和 OneBot 配置。先在手机上确认机器人，再核对返回的 AppID，点击**保存此账号**。保存后，已停止的连接仍保持停止；已开启的连接会使用新凭据重新连接。

**何时通知**有**通知规则**：**发送通知**总开关、安静时段、**跳过正在查看的会话**和**跳过短任务**。**各通道接收哪些提醒**表格每行一个推送通道，每个事件一列复选框，分别对应**对话结束**和**等待回答的问题**；**对话结束**采用同一工作收尾判定。这里是选择通道接收哪些事件的唯一位置；每个通道行内不再提供事件复选框。之前关闭的总开关、连接和通道保持关闭。新配置默认开启，**跳过短任务**默认 `0` 秒，短答也能通知；提高此值只筛掉通道中的短任务通知，不改变完成的含义。通道规则保存在所连服务端。

**本机**标签的**系统通知**里的**允许系统通知**控制本设备的会话通知和跨空间待处理提醒。默认开启的**对话结束后通知**在你没有查看对应对话时通知，包括正在 Kiki 中查看另一对话或设置的情况。这里的结束是本次交办工作已收尾：主智能体已回复完毕，有限后台任务与 subagent 已收尾，结果和自动续跑也已处理完。仅一轮结束不会通知。常驻服务器、监听器和未来定时任务不会一直阻止通知；等待审批、提问、失败和用户停止不算完成。浏览器使用需要允许本站发送通知；若已拒绝，可在地址栏的网站权限中恢复。

打开收到提醒的对话，才会清除它的未读角标。让 Kiki 获得焦点、查看主页或设置、打开另一对话，都不会把它标成已读。点击通知会打开原空间、原连接中的同一对话，其它对话仍保持未读。留在隐藏或失焦窗口里的对话，要等你返回查看时才会标记已读。短暂断连或重开应用后，Kiki 会接续运行中服务端保留十分钟的完成记录，不重复本设备已观察到的通知；首次启动不会补发历史完成通知。系统通知开关保存在当前设备。

## 搜索与抓取

**设置 → 能力 → 搜索与抓取**打开**概览与配置来源**（`/settings/search`）。旧地址 `/settings/environment-tools` 打开这一页；那里的 `tab` 只在取值为 `overview`、`search`、`fetch`、`providers` 或 `advanced` 时选中对应的搜索标签。这里查看内置搜索与抓取模块（`WebSearch` 和 `FetchURL` 两个工具背后的能力）当前生效的配置来源，并控制服务器是否复用本机的搜索配置。对应的配置位于 `config.toml` —— 见[配置文件](../configuration/config-files.md#nb-search)。

同一处的**高级与诊断**标签页里有一张**全文索引**卡片，用于搜索你自己的会话历史。首次索引在后台建立，优先处理最近的会话，卡片会显示已完成的数量。如果索引因可处理的原因停下，这张卡片会出现**重启索引程序**按钮；索引被配置关闭或不可用时则没有可重启的对象，卡片直接说明原因。

## 浏览器控制

**设置 → 能力 → 浏览器与电脑**会打开**浏览器控制**标签（`/settings/browser-control?tab=browser`），集中呈现浏览器总体状态结论、连接主列表与四类接入来源。**电脑控制**是第二个标签。

**允许使用浏览器**位于页面最上方，旁边是一行总体结论，直接说明当前是否允许使用浏览器、已允许几个连接、默认连接是谁，或第一个阻塞门禁是什么。除非此服务机已经把它关掉，否则它保持允许。**默认开启**决定新会话是否一开始就带上这些工具。某个会话可以关掉它们，也可以在仍允许时再打开。下次模型请求使用这个选择。允许开关不改变已安装的浏览器。开关让浏览器工具可供使用，但仍受本会话的工具设置限制。如果已打开的会话保留了旧工具选择，**应用当前工具设置**会先显示目标会话，经确认后只更新工具，不改变提示词、模型或历史；显式工具选择和已禁止的工具仍受限制。工具来源不明的旧绑定不会自动扩权。

在**浏览器连接**下，所有已保存的浏览器统一列在一张列表中，每行显示**允许 Agent 调度**勾选框、连接类型、所在位置、运行状态，以及当前默认项的只读**默认**标签。勾上某一行，Agent 才能使用该浏览器；取消勾选即刻收回这项允许。列表顶部的**默认连接**是选择新会话默认浏览器的唯一入口；选**每次指定**则不保存默认。允许哪些浏览器和选哪一个做默认彼此独立：取消勾选不会挪动默认（若当前默认未被勾选允许，顶部结论会明确提醒），设默认失败时已允许的浏览器保持原样，方便直接重试。

点击列表右上角的 **+ 添加浏览器** 会展示 Kiki 可准备或检查的四类浏览器来源，以及底部的**手动配置**；同样的四类来源也收纳在连接列表下方的**浏览器来源**折叠区中，便于随时管理开关与组件更新：

- **Kimi 浏览器扩展**：控制你日常使用的浏览器，沿用自己的登录状态。Kiki 安装插件和本地桥接程序；扩展由你在浏览器商店添加并批准。已有可用桥接程序即使版本与随附下载版本不同，也可连接。**高级选项 → 检测与更新**下载经过校验的发行版本；更新失败保留原安装，已运行的桥接程序继续使用原版本。该来源内的 **WebBridge 就绪状态**折叠区说明本地桥接是否可用，提供**重新检查**，并在缺少组件时提供需要确认的**设置 WebBridge** 操作。
- **独立浏览器**：Kiki 管理一套独立的浏览器和登录状态。**一键配置**下载所需组件，**连接**启动控制，**打开浏览器**打开或激活窗口。**高级选项**提供**检测与更新**，Windows 服务机还提供**创建桌面快捷方式**。更新不会切换已运行的浏览器；快捷方式创建在服务机桌面上，不覆盖已有无关快捷方式。
- **Codex / ChatGPT 浏览器扩展**：这是 Codex 或 ChatGPT 桌面端及其浏览器扩展的接入来源。**一键配置**准备桥接组件。已发现但尚未加入连接列表的管道会列在**在这里发现、还没保存。勾选即保存并允许 Agent 使用。**下：勾选某一条会先保存这条连接，再允许 Agent 使用它，并且不改当前默认。这些是尚未验证的端点候选项（桌面应用工具也使用同一管道名称前缀），因此在浏览器握手成功前会标为**授权待确认**。保存不会打开管道、批准扩展、注册本机宿主或重启浏览器。应用或扩展真正发出权限请求时，Kiki 才会处理那次请求。**官方说明**仍留在这一路。如果没有列出候选项，请检查官方宿主与运行时诊断；仅凭空列表不能判断扩展未启用。保存失败时勾选会保持空着，页面写明原因，可以再试。
- **Ego Lite**：从官方下载页自行安装 Ego Lite，并完成它自己的设置窗口。Kiki 不会安装 Ego Lite，也不会导入 Chrome 的数据。这里没有安装组件的按钮。尚未安装时，这一行给出下载链接。已经安装且它自己的设置已经完成时，这一页会检查该安装并可以显示为就绪；Ego 自己的设置窗口还没完成时仍显示未完成，进程仅仅退出也不算就绪。**检查 Ego Lite** 会再检查一次。就绪但尚未保存连接时，勾选**在这里发现、还没保存。勾选即保存并允许 Agent 使用。**下的条目即可保存并允许使用。连接上的高级项是 CLI 路径、可选的 profile id 和可选的服务名称。

每个来源有自己的开关。关掉一个来源后，这个来源不再被发现、连接或调用。此前勾选的连接仍保持勾选；重新打开该来源时，恢复的是这些已勾选的连接。原先没勾的连接，包括来源关闭期间新发现的连接，不会被自动勾上。

每个来源行都写明自己的状态和**还差哪一步**，并把下一步放在同一行：缺组件时是**一键配置**，只差商店授权时是商店链接，只差浏览器控制能力开关时是**允许浏览器控制**。Kiki 能装的都装好之后，Kimi 和独立浏览器这两项就不再催你安装。分步详情收在**此服务检测了什么**折叠里。

**允许浏览器控制**就是同一个同意动作，就在本页。只差浏览器控制能力开关时，那一次确认会补上还缺的组件（组件已齐则一个都不装）、启用插件，并允许在这台服务上使用浏览器控制（启动或附着浏览器）——三项在确认前都会写明。浏览器控制默认可用；组件仍需经确认配置，连接也只在请求时启动。你明确确认这项操作时，也可恢复之前保存的关闭选择。

如果本页之外有东西把浏览器控制关着——某个环境变量，或该主机上的运行时覆盖——这里任何操作都改不动。该项会直说这一点，而不是给一个按了也没用的按钮；**看是什么把它关着**会指出具体的覆盖来源。

在**浏览器连接**中点击任一行，列表会切换为该连接的详情视图，顶部带返回列表按钮与只读的**允许使用**／**已停用**标签（连接授权统一在列表勾选框中切换）。升级后已有连接保留原 id、类型和默认选择，不按显示名称改换接入方式。已保存的 Codex 连接可以在这里改名，不改变它的运行时或浏览器绑定。在 **+ 添加浏览器 → 手动配置** 中，可选择以下三种接法创建连接：

- **独立 Agent 浏览器（Profile）**：Kiki 在服务机上启动并管理它自己的浏览器，使用它自己的 profile（登录态），不会复制你日常浏览器的 cookie。可选：改用已安装的 Chrome 或 Edge，以及**显示浏览器窗口**（默认关闭，即无头运行）。
- **已有或远端浏览器（CDP）**：附着到已经开放 CDP 地址的浏览器，不新启动任何东西。该地址指向浏览器所在的那台机器，可能是另一台机器。
- **Kimi WebBridge**：创建绑定到服务机本地 Kimi WebBridge HTTP 桥接的连接，无需填写端点地址。

每条连接都可以单独**检查**、**连接**、**断开控制**。检查会启动受管驱动并读取会话与标签状态，CDP 连接则与端点握手并列出目标，Kimi WebBridge 连接则检查本地桥接，三者都不会打开页面。保存只写配置，并会先结束该连接当前正在运行的会话。**断开控制**释放该连接：借用的 CDP 或 WebBridge 浏览器保留，Kiki 启动的实例会关闭。**默认连接**只对新创建的会话生效；关闭一条连接不会自动换上另一条。

驱动，以及 Kiki 启动的任何浏览器，都运行在 Kiki 服务机上，而不是显示这个窗口的设备上；组件存放在运行它们那台机器的 `<Kiki home>/browser/resources` 下。

Agent 通过[浏览器工具](../reference/tools.md#浏览器类)使用这些连接，并且只按连接 id 指定，不按显示名称。能力开关与连接本身分别保存在 [`[experimental]`](../configuration/config-files.md#experimental) 和 [`[browser_control]`](../configuration/config-files.md#browser-control)。

## 插件

**设置 → 能力 → 扩展与工具**（`/settings/extensions`）有三个标签：**插件**（默认，`/settings/plugins`）、**技能**（`/settings/skills`）和 **MCP**（`/settings/mcp`）。**插件**标签列出已安装的插件。每一行显示插件自己的名称、来源、版本、当前是开启还是报错，并带一个开关，不必离开列表就能停用它。顶部的**去市场里找插件**是安装新插件的地方。

选中某个插件会打开**它自己的设置页**（`/settings/plugins?plugin=<id>`）：插件名称与状态、返回列表的入口、设置内容与开关。已启用的插件可以提供自己的设置面板。面板可以沿用本应用的颜色和语言；不处理语言时，仍显示插件自带的原文。否则 Kiki 显示清单中声明的字段。声明了分组的字段按组放在一起；秘密字段只显示已保存，不会把原值显示出来。改动后才出现**保存**与**放弃**。保存失败时，草稿和上次已保存的值都还在。插件界面加载失败时，可以**重试**，也可以使用这些字段。带着未保存的改动离开会先询问。

**卸载插件**在页面底部，卸载前会先确认，并说明会一并带走什么，与[插件管理器](../customization/plugins.md#安装与管理)一致。既没有设置字段、也没有自带设置界面的插件仍有这个页面，开关与**卸载插件**照常可用。

这一页有独立的地址，可以复制、刷新，也可以用浏览器的前进后退回到同一个插件。**扩展与工具**页上的**插件设置**入口会跳到这里，[媒体来源](../customization/plugins.md#配置一个来源)上的插件按钮也是。

## 工作区

**设置 → 会话与工作 → 工作区**（`/settings/workspaces`）列出服务端已知的文件夹。打开一行即可在独立详情页（`/settings/workspaces?workspace=<id>`）修改名称、置顶、选择[插件默认值](../customization/plugins.md#选择插件在哪里使用)，或将记忆设为继承、开启或关闭。根目录路径用于确认对象，不在这里修改。

**工作区信任**决定 Kiki 是否加载项目自己的配置、MCP servers 和 hooks，以及是否允许项目 profile 指定外部执行器。只有明确操作开关才会改变信任；打开详情页不会授予信任，也不改变工具审批模式。**Agent**、**MCP servers** 和 **Skills** 入口保留当前工作区目标。Profile 沿用原文件来源与写入范围；插件和项目文件中的 MCP 条目只读，可编辑的用户级条目仍写入用户配置，不会复制成新的工作区配置。工作区不存在时会明确显示，不会悄悄切到另一个。

## 电脑控制

**设置 → 能力 → 浏览器与电脑**的**电脑控制**标签（`/settings/computer-control` 打开这个标签）按「总体状态结论与安装 → 电脑控制连接 → 模型使用倾向」的顺序集中展示当前服务机状态。桌面操作通过固定版本的开源执行器，发生在运行 Kiki 服务的那台机器上；页面不会自动安装执行器或连接桌面。

**允许使用电脑控制**位于这一标签最上方，旁边是一行总体结论，直接说明当前是否允许驱动桌面、正在使用哪条连接，或第一个待解决的门禁（例如当前使用 CUA 路径且尚未安装时直接提供**安装执行器**按钮）。除非此服务机已经把它关掉，否则它保持允许。**默认开启**决定新会话是否一开始就带上这些工具。某个会话关掉后，这些工具不再提供给该会话。允许开关关掉后，任何地方都不再提供，包括点名了它们的任务。拨动允许开关会更新一条已经在运行的电脑连接所提供的工具。工具策略仍可能禁用这些工具，或只禁用其中一部分，页面会写明。这个开关不安装执行器，也不连接桌面。下面的使用倾向不授予也不收回工具。

**安装执行器**会下载并校验该发行物，然后注册一条名为 `kiki-computer` 的全局 MCP 连接（驱动路径加上 `mcp` 参数）。**随附 CUA 执行器**行上的**已安装**只表示随附文件校验通过——不代表真的能控制桌面，安装过程也不会去检查这一点。机器状态行会标明将被控制的主机（**Kiki 服务机**就是当前连接的服务，因此在远端或 SSH 连接下，桌面属于那台主机自己的图形会话），并提供**检查状态**按钮与**安装详情**折叠区以查看分步校验结果。

在**电脑控制连接**下，列表顶部的**当前执行连接**选择由哪条电脑 MCP 连接执行（默认为 CUA 默认路径），右侧的 **+ 手动添加**可新建自定义连接。点击任一连接行会将列表切换为该连接的详情表单（顶部带返回列表按钮），可编辑程序路径、启动参数、执行器或环境变量，也可直接**测试连接**或**停止控制**。在 Windows 服务机上，列表下方的**登记已安装的 Windows-MCP 0.8.8 独立环境**折叠区可将已有的 Python 解释器与 `--config` 配置文件写入全局 MCP 配置，不会执行 `uv`、`install`、`auth` 或 `serve`，也不会自动切换当前执行连接。

**模型使用倾向**只引导模型，不授予也不收回上面那个开关和工具策略已经决定的权限。默认选**更不倾向**：除非你或你的规则明确要求，否则模型一般不用电脑控制，优先已有 CLI、API、MCP、短脚本及浏览器专用能力。**更倾向**让模型偏好用电脑控制处理适合的交互任务；两种选择都尊重你当前明确要求、工具可用性、正确性和权限。点击**更不倾向**或**更倾向**会立即保存，并在下次模型请求生效，不改变工具权限或安装状态；若保存失败会自动回退为已存储的值并提示错误。来源标签显示当前生效的配置层；**恢复继承**删除此服务机的覆盖，采用上层值，继承值也可能是**更倾向**。

每个会话的 main agent 通过现有 [MCP](../server/mcp.md) 机制与权限使用执行器自带的工具。子 Agent 需要显式开启电脑工具，使用倾向不会替它开启工具。字段与工具选择规则见 [`computer_control`](../configuration/config-files.md#computer-control)。固定版 Windows 执行器只观察主屏，无法自行选择显示器。macOS 上桌面权限由调用进程承载，需要时在驱动报告缺失处授予。

**停止控制**会结束本服务启动的 cua 进程并停用可编辑连接的配置；其他客户端或另一个 Kiki 实例可能仍在操作该桌面。

## 输入框（Composer）

**设置 → 应用 → 常规**（`/settings/general`）的**输入与会话**卡片上有**保留输入草稿**（英文界面为 Persist composer drafts）。它控制新会话选择（模型、思考强度、工作区、工作目录、profile）和每个会话的草稿文本是否写入当前浏览器。关闭开关会清空已保存的存储。见[工作区与会话管理](./sessions.md#会话存储)。

## 派遣能力

在**设置 → 模型与智能体 → 智能体 → 智能体配置**（`/settings/agents`）打开一份配置档案，用**子智能体**决定这一个智能体能创建什么。**子智能体与派发**标签（`/settings/agents?tab=dispatch`）设置对所有配置档案生效的默认值：默认子智能体、子智能体模型规则、子智能体面板的打开方式和工具设置。**允许创建子智能体**可以是**未声明**、**允许**或**已关闭**。**未声明**沿用这份档案的上层。**已关闭**时，它不再创建子智能体，按路径提供的定义也停用。**预设名单**选择它可以启动的具名预设和路由；灰色的值是子智能体自己的，在这里填写才会覆盖。**优先推荐**只排顺序。**禁止派遣**会拒绝这些名字，即使预设名单本来允许。缺少的模型或预设会标在这份档案上，与是否允许创建子智能体分开。见 [Agent 与 subagent](../customization/agents-and-subagents.md#重建会话上下文)。

## 会话控制

会话控制仍在 `/settings/sessions`（**会话与工作 → 会话**）。**会话与工作 → 工作区**打开的是工作区，不代替这些地址。

这一页还包含**任务与后台策略**——同时运行几个后台任务、Bash 任务的超时，以及非交互运行遇到未结束的后台任务时怎么做。任务字段保存在 [`background`](../configuration/config-files.md#background) 下。定时任务运行时的只读诊断 **Cron 运行参数**位于**高级 → 开发与实验**（`/settings/developer#st-card-cron`），已有 cron 链接也会打开这里的卡片。

**导入历史**（`/settings/sessions/import`）打开 Kiki 内置的导入器，也可从**新会话**进入。内置格式无需安装或启用插件，详见[会话历史导入](../customization/plugins.md#会话历史导入)。

`/settings/sessions` 上的**管理归档对话**打开 `/archived`，可浏览、搜索和阅读归档对话，也可永久删除单项或当前连接 home 中的全部归档。删除前会确认，失败条目会保留在结果中供核对、重试。删除范围见[归档管理](./sessions.md#gui-会话恢复与活动历史)。

`/settings/sessions` 上的**会话标题**也可编辑自动写标题时使用的提示词。卡片标明当前采用内置默认还是自定义；**展开**以只读方式显示服务端的内置默认稿。编辑**自定义提示**后保存，或选择**恢复默认**删除覆盖；保存空白提示也会回到默认稿。保存失败时保留草稿。这些操作不改变标题模型、已选生成时机或自动标题开关，只影响下一次标题请求，已有标题保持不变。字段参考见 [`session_title`](../configuration/config-files.md#session-title)。

### 提示词生效详情

在会话标题栏打开 **⋯ → 提示词生效详情**。抽屉独立于右侧栏，窄屏也能打开，显示当前 Agent 身份、profile、模型与执行器，提示词通道及来源顺序，各字段覆写状态与原因，文件位置和 cognition anchor 的作用域。

绑定与磁盘版本有助于识别改动的来源文件。要真正重新加载会话的提示词来源，请在会话空闲后使用[重建上下文](../customization/agents-and-subagents.md#重建会话上下文)。**检查所有分支**是另一项操作，只查看已配置的共用、主 Agent 与独立 Agent 提示词文件，不切换当前身份。

### 驾驶舱

桌面宽度下，右侧面板标题栏的**标准 / 驾驶舱（Standard / Cockpit）**在常规宽度和加宽并接管预览区之间切换。两种状态下对话与输入框都留在主栏；选**标准**或**退出驾驶舱**会恢复原来的预览内容、标签、草稿和宽度。打开文件、Agent 详情或 Skill 预览同样会退出驾驶舱。

## Usage

从侧栏打开**用量（Usage）**页（`/usage`）。标签顺序是**实时（Live）**、**历史（History）**、**额度（Quotas）**、**外部同步（External sync）**。地址里没有历史筛选、也没有 `panel=` 选择时，打开的是**实时**。已经带历史筛选的地址，以及 `panel=history`，打开**历史**。`panel=realtime` 和 `panel=limits` 打开**实时**。

- **实时（Live）：** 模型请求与运行中的智能体上下排列，各有可展开的详情。请求详情显示本服务所有会话的原生请求运行数与排队数，可按模型、供应商、角色查看，以及排队行的阻塞规则 ID 与等待时间。智能体详情显示主智能体、子智能体及独立智能体的执行数，可按执行器、profile、模型或角色查看；连接失败时标明最后计数已过期。同一标签内的「并发限制」可新增或编辑规则，选择模型或供应商目标，设置全服务共享或每会话独立的上限。开关可暂停规则，不删除其内容；保存后对新请求与排队请求生效，不终止正在输出的流。
- **历史（History）：** 某个日期范围的费用与 Token 用量，默认为今天。从趋势柱查看消费来源，再按需打开会话记录与已记录轮次；筛选随视图保留。前期比较只在请求时读取。Token 与费用有各自的完整度指示，「数据可信度」区分未知计量与空区间。已有带筛选的用量链接打开历史页。见[用量统计](./sessions.md#gui-用量统计)。
- **额度（Quotas）：** 显示已配置供应商和服务报告的余额、点数、用量窗口等指标，与 Kiki 本地用量计量分开。卡片列出来源账号、状态和可用指标，需要认证时提供对应的登录或设置入口。登录后重新读取账号和本地缓存的额度状态，不会自动查询厂商，也不会开启已暂停的额度检查。点「刷新额度」刷新符合条件的来源，或用卡片上的刷新操作只更新单个来源。缺失或不支持的指标不按零余额处理。
- **外部同步（External sync）：** 接收本服务自己用量的目的地，有三种：**vibecafe.ai**、**Kiki webhook** 和**脚本（Script）**。外送的只有模型、UTC 半小时、四项 Token 计数、质量与费用——不含提示词、回复、标题、工作区名或路径。

  **vibecafe.ai** 目的地直接在页面上登录：点**登录 VibeCafe**，在浏览器里确认页面给出的验证码，无需填写地址、client id、密钥或选择保存方式。Kiki 将凭据保存在当前连接的服务器上，优先使用系统钥匙串；不可用时改存私有文件，由文件系统权限保护，并非静态加密。重启后保留已保存的连接。保存失败时点**重试**，原有凭据会保留。若要提供自己的端点或密钥，请选择 **Kiki webhook**。

**Kiki webhook** 目的地填写你自己的 HTTPS 端点，认证可选 `none`、`bearer` 或 `hmac`，并可开启 gzip。密钥要么存进系统钥匙串，要么由你显式选择存成服务器上的私有文件——钥匙串失败会直接报错，不会悄悄改成文件；私有文件靠文件系统权限保护，并非静态加密。

已有 `/usage?panel=limits` 链接会打开「实时」并定位到并发规则区，不再有单独的「限制」标签。

外部同步无需实验开关；没有目的地时不会发送数据。登录只保存批准的凭据，目的地仍是**停用**状态，也没有给过同意。选目的地、预览确切内容、同意一次，再启用。

没有同意过的目的地不会发送数据。扩大时间范围、更换端点，或凭据换成了另一个身份时需要重新同意，缩小范围或调整周期不需要。**暂停**，以及 vibecafe.ai 目的地上的**停用同步**，会停止外送（`enabled` 为 false，状态为 `disabled`，没有下次时间），保留队列和已登录的账号。移除会询问是否丢弃排队数据，并删除已存凭据；请服务方删除它已持有的用量则是另一项操作。

升级时，已退休的 `usage_export` 开关若被显式关闭，会将已有目的地暂停一次，保留同意记录与排队数据；需要继续发送时逐个恢复目的地。终端侧的对应做法见 [`kiki usage-export`](../reference/command.md#kiki-usage-export)。

**脚本**目的地以你自己的 OS 用户和普通权限运行你的命令——它可以自行读取文件或访问网络，这不是沙箱。Kiki 只把不含内容的批次写入它的 stdin，并从输出读取 receipt（回执）。

请求看似卡住时，先打开「实时 → 请求详情」再改上限：排队行会指明本地阻塞规则，供应商 HTTP 429 要看供应商自己的报错；本地队列满、等待超时、立即拒绝需要不同的调整。字段、示例与错误码见 [`request_governance`](../configuration/config-files.md#request-governance)。这些规则管辖的是本服务自己发出的模型请求：当你把一轮交给 Codex、Claude Code 或 Grok Build 当引擎时，那些请求属于引擎自己，不计入这里；而外部工具回过头来让 Kiki 跑原生请求，则照常计入。

## CLI 侧对应

TUI 没有**设置**对话框。终端侧的偏好（主题、编辑器等）在 `tui.toml` 里配置，或用交互命令 `/config`、`/theme`、`/editor`——见 [`tui.toml`](../configuration/config-files.md#tui-toml)。Agent 与运行时设置在 `config.toml`。
