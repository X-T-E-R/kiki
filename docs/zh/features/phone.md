# 手机会话

连接 IM 账号后，可以把每个信道分别接到角色的日常会话或你选定的线程。同一账号下的不同联系人、聊天或平台支持的群话题可以使用不同目标。打开 **设置 → 通知与消息**，页面按 **双向对话**、**通知推送** 和 **本机提醒** 分页展示，默认打开 **双向对话**。

粘贴一段配置并检查，或在这一页用微信扫码。微信这条路径不需要令牌，也不需要填写数字编号。在已连接的账号下选择 **新增渠道**，开启监听，再从要添加的联系人、群组或话题发送消息。Kiki 显示发信人、信道和预览；为这条发现选择角色或线程，再点 **绑定**。每条发现都有自己的目标，添加其他信道无需重新扫码或粘贴配置；粘贴内容里的聊天编号不会成为绑定。当前微信连接只支持私聊，不同联系人可各自绑定；群聊发现会保留，但绑定按钮禁用。

账号授权过期时，选择该账号的 **重新授权**；连接停止时，选择 **重试连接**。重新连接中的账号会在有诊断时显示失败原因，展开可查看数字详情。

每条已绑定信道都有自己的目标、**IM 对话**开关和 **选项**。可在这里改目标、忙碌策略、消息正文方式、审批与提问，或恢复绑定默认值。修改目标或重新确认暂停的绑定不会把它开启；请明确启用，并核对它的对话开关。

新绑定默认 **立即** 投递：回合正忙时，Kiki 会尝试在下一处安全步骤把消息送入当前回合。你可以在 **选项** 中改为 **排队**，或保留原有 **插入** 策略；已保存的选择不会被重置。如果当前回合不能接收消息，它会留在队列或独立开一轮，Kiki 只会在实际排队时提示排队。在已绑定的聊天中发送 `/help` 可查看可用命令；`/status` 查询状态，`/abort` 停止当前回合，`/target` 查看绑定目标（切换需到 Kiki 确认）。未知斜杠命令会得到提示，不会作为 Agent 消息发送。

手机上可以在回合结束时看到完整可见正文，也可以看到已经写出的正文。多道题会一起保留，直到每一题都有答案。还没处理完的审批和提问，在 Kiki 重启后仍可从手机回答。QQ 和微信上，每个数字回答下一道未完成的题；不是选项里的文字也算在这道题上。要求输入口令的登录留在桌面的 SSH 界面。可见正文还没发完时 Kiki 重启，手机会继续收到剩余部分，这个回合不会重新开始。

QQ 和微信使用完整正文模式，不支持修改已发消息或显示按钮，手机上用选项数字回答。QQ 不能接收文件；通用 OneBot 桥也没有可识别的消息过长错误类别。QQ 拒绝的正文不算已送达，完整回复仍可在桌面查看；Kiki 不会把不明失败当成过长而自动拆分重发。微信因消息过长拒绝时，完整正文会作为一份文件发出。平台不能按语音发送的声音会按原始文件发送，并单独计数。

单向通知通道不变。如果机器人已经设置了 webhook，页面会说明，并保留那个 webhook。

## 留在这台电脑上的内容

令牌存在现有的通知凭据里。它不会写入会话，也不会写入诊断日志。尚未绑定的人发来的消息只被计数，不会开始一个回合。
