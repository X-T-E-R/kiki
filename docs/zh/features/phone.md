# 手机会话

手机会话把一个已配对的聊天接到角色的日常会话，或接到你选定的会话。打开 **设置 → 通知与消息**。手机会话放在通知规则和单向通道之间。

粘贴一段配置并检查，或在这一页用微信扫码。微信这条路径不需要令牌，也不需要填写数字编号。已有连接可以不再粘贴配置就再次检查。然后用手机发一条消息。Kiki 显示发信人、聊天和一段预览。把这个发信人绑到角色的日常会话，或绑到一个已有会话。粘贴内容里的聊天编号不会成为绑定。连接处于接收中时，新的手机消息会显示在这一页上。

已绑定的一行可以改到另一个会话，开关手机交互，或重新跟随新绑定的默认。回合正忙时，下一条手机消息可以排队，也可以插入当前回合。手机上可以在回合结束时看到完整可见正文，也可以看到已经写出的正文。多道题会一起保留，直到每一题都有答案。还没处理完的审批和提问，在 Kiki 重启后仍可从手机回答。QQ 和微信上，每个数字回答下一道未完成的题；不是选项里的文字也算在这道题上。要求输入口令的登录留在桌面的 SSH 界面。可见正文还没发完时 Kiki 重启，手机会继续收到剩余部分，这个回合不会重新开始。

QQ 和微信都会发送完整正文，也不能修改已发出的消息。它们不显示按钮，手机上用选项数字。QQ 不能接收文件。QQ 因消息过长拒绝时，手机会按顺序收到拆开的同一段正文，接起来仍是原文。已经发出的几段留在手机上，没发出去的后文会再补上。短到不能再拆仍然过长时，手机会收到一句说明，全文留在桌面会话里。微信因消息过长拒绝时，完整正文会作为一份文件发出。平台不能按语音发送的声音会按原始文件发送，并单独计数。

单向通知通道不变。如果机器人已经设置了 webhook，页面会说明，并保留那个 webhook。

## 留在这台电脑上的内容

令牌存在现有的通知凭据里。它不会写入会话，也不会写入诊断日志。尚未绑定的人发来的消息只被计数，不会开始一个回合。
