# 手机会话

手机会话把一个已配对的聊天接到角色的日常会话，或接到你选定的会话。打开 **设置 → 通知与消息**。手机会话放在通知规则和单向通道之间。

粘贴机器人令牌，或一行一个字段的短配置。检查后，用手机发一条消息。Kiki 显示发信人、聊天和一段预览。把这个发信人绑到角色的日常会话，或绑到一个已有会话。粘贴内容里的聊天编号不会成为绑定。已有连接可以不再粘贴令牌就再次检查。连接处于接收中时，新的手机消息会显示在这一页上。

已绑定的一行可以改到另一个会话，开关手机操作，或重新跟随新绑定的默认。回合正忙时，下一条手机消息可以排队，也可以插入当前回合。手机上可以在回合结束时看到完整可见正文，也可以看到已经写出的正文并就地更新。长文保持完整：按平台长度分段；平台能收文件时，特别长的消息改成文件发送。多道题会一起保留，直到每一题都有答案。审批和提问可以在手机上回答。要求输入口令的登录留在桌面的 SSH 界面。

QQ 和个人微信不能修改已发出的消息，也不能显示按钮。手机收到的是完整正文和选项数字，页面不会把这两种能力显示成已经可用。QQ 不能接收文件。平台不能按语音发送的声音会按原始文件发送，并单独计数。

单向通知通道不变。如果机器人已经设置了 webhook，页面会说明，并保留那个 webhook。

## 留在这台电脑上的内容

令牌存在现有的通知凭据里。它不会写入会话，也不会写入诊断日志。尚未绑定的人发来的消息只被计数，不会开始一个回合。
