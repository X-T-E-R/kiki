# 外观

Kiki 可以长得像你的编辑器，而不是像所有人的编辑器。**皮肤**决定 GUI 的配色、字体、圆角和密度；**背景**可以把一张图片或一段视频放在窗口后面；**外观包**把配色和素材打包在一起。这一节讲的都只改变外观，不改变行为——皮肤是纯声明式的，所以它没法藏起审批提示，也没法运行代码。这一页讲内置皮肤、挑选与微调、背景，以及外观包。

## 六套内置皮肤

每套皮肤都带浅色和深色两个变体，用哪个由皮肤选择器上方的浅色 / 深色开关决定。**High contrast × Obsidian** 是在默认不够时用的那一套。

| 皮肤 | 它是什么 |
| --- | --- |
| **Paper × Inkstone**（默认） | 暖白纸面和墨蓝标记；入夜是冷炭灰配铜色。 |
| **Porcelain × Deepwater** | 冷白纸面和钴蓝细节；夜里是层叠的藏青配雾蓝控件。 |
| **Celadon × Night Garden** | 青瓷釉色和柔白纸面；夜里是深松绿配玉石细节。 |
| **Apricot × Afterglow** | 杏白纸面和浆果色控件；暗色是梅子炭灰层配桃色光。 |
| **Iris × Starveil** | 紫罗兰白纸面和鸢尾墨色；暗色是靛紫层配银丁香控件。 |
| **High contrast × Obsidian** | 可见边框和 AAA 正文对比度；暗色是层叠炭灰、冰青焦点和近白控件。 |

完整表格和已退役的配色见[内置皮肤](/zh/customization/skins#内置皮肤)。

## 选一套，然后微调

**设置 → 外观**里换皮肤会立即生效。可以选内置的、选主题文件夹里的、选已启用插件贡献的，或者选已安装外观包的配色。在你选的基础上，可以覆写**强调色、字体、圆角和密度**——每一处改动即时生效，**恢复默认**可以一次全部撤销。

**导出为皮肤文件**会把你当前看到的写成一个 `.json` 皮肤文件，可以自己留着或分享。首次启动的**语言与外观**页有同样的浅色 / 深色选择、内置配色，以及一个可选的背景图。

皮肤是 GUI 的；终端有自己的一套**主题**，放在同一个 `~/.kiki/themes/` 目录里，靠内容区分（带 `"kind": "kiki-skin"` 的是皮肤，别的都是 TUI 主题）。两个加载器各自忽略对方的文件，所以可以并排放着。见[自定义主题](/zh/customization/themes)和 [GUI 皮肤](/zh/customization/skins)。

## 背景图片或视频

**设置 → 外观 → 背景**可以把一张图或一段短视频放在窗口后面。选本地文件（PNG、JPEG、WebP、AVIF、GIF、MP4 或 WebM，图片最大 25 MB，视频最大 100 MB）——它留在这台设备上，不会上传，所以连到远端服务端的浏览器标签页也能用；或者粘贴一个 `https` 链接，服务端取一次并把副本留在本地，这样它既不会追踪你、离线也能用。接着选**显示在**（整个窗口、仅对话区，或仅侧栏）、**填充方式**、**锚点**、**图片强度**、**模糊**、**亮度**和**柔化**，再加**面板不透明度**和**面板模糊**决定侧栏和对话区透出多少画面。**浅色深色分别设置**可以为每个主题选不同背景。

无论怎么选，文字都保持可读。Kiki 会测量图片，必要时抬高**面板不透明度**，让最淡的文字对图片最暗和最亮的部分都保持 WCAG AA（4.5:1）对比度，并且会说明它这么做过。菜单、对话框、审批提示和输入框卡片始终保持实底。视频静音循环播放，并在窗口隐藏、开启了减弱动效、或者电量低且未接电时停在第一帧。见[背景图片或视频](/zh/customization/skins#背景图片或视频)。

## 外观包

外观包把配色和背景素材、美术打包成一次安装。它可以同时设置皮肤和背景，也可以带随包分发的链接图片。外观包只能装外观——它不改行为、不安装插件、不加工具。见[外观包](/zh/customization/skins#外观包)。
