# 浏览器与电脑控制

当工作走出本地文本文件，需要打开网页、操作已登录后台，或是驱动没有 CLI 与 API 的桌面软件时，你可以在 **设置 → 能力 → 浏览器与电脑**（及对应插件）中按需配置并启用浏览器与电脑控制。

Kiki 自身的浏览器驱动、由它启动的独立浏览器和电脑控制都运行在 Kiki 服务机上；你也可以直接连上本机或远端已有的浏览器。完整设置说明见 [浏览器控制](/zh/guides/settings#浏览器控制) 与 [电脑控制](/zh/guides/settings#电脑控制)。

## 浏览器控制 {#浏览器控制}

在 **设置 → 能力 → 浏览器与电脑 → 浏览器控制** 中完成组件配置并勾选允许使用的浏览器后，智能体即可通过 [浏览器工具](/zh/reference/tools#浏览器类) 打开网页、读取页面快照、点击元素、填写表单与截图保存，并将截图或录制自动附回对话时间线。连接只在任务实际请求时启动，不会在后台常驻打开页面。

你可以按任务需要选择不同的浏览器接入方式：

- **日常已登录的浏览器（Kimi / Codex 浏览器扩展）**：通过 **Kimi 浏览器扩展**或 **Codex / ChatGPT 浏览器扩展**操控你平时正在使用的浏览器，直接沿用已有的登录状态与 Cookie。适合在已登录的内部后台、社媒平台、招聘网站或比价页面上执行检索、填表与跨站点整理。Kiki 负责准备本地桥接组件，你在浏览器商店添加扩展并批准后即可连接。
- **Kiki 管理的独立浏览器**：由 Kiki 在服务机上启动并管理一套独立的浏览器与专属登录态，不会复制你日常浏览器的 Cookie。适合自动化验证、无状态抓取或需要隔离账号的网页操作。默认无头运行，也可以打开窗口实时查看。
- **Ego Lite**：如果你自行安装了 Ego Lite 并完成了它的初始化设置，Kiki 可以检查就绪状态并接入该连接，让智能体运行页面自动化脚本并将截图直接附回时间线。
- **已有或远端浏览器（CDP）**：在 **+ 添加浏览器 → 手动配置** 中，可以直接附着到任何已开放 CDP 地址的本机或远端浏览器，无需新启动浏览器实例。

### 浏览器授权与默认项

每条浏览器来源都有控制该接入方式的启用开关（关闭来源会停止该来源的发现、连接与工具调用，并保留原本已勾选的浏览器记录），连接列表中的每个浏览器则通过 **允许 Agent 调度** 勾选框决定是否授权使用。只有被勾选的浏览器才能被智能体调用；取消勾选即可随时收回权限。你可以同时允许多个浏览器，并在列表顶部的**默认连接**中指定其中一个作为新会话的默认浏览器，或设为**每次指定**。

各条接入路由的配置步骤与桥接状态检查见 [设置页导览：浏览器控制](/zh/guides/settings#浏览器控制)，工具参数与调用方式见 [内置工具：浏览器类](/zh/reference/tools#浏览器类)。

## 电脑控制 {#电脑控制}

遇到没有 CLI 或接口的桌面应用、跨软件信息录入，或需要像真人一样走查客户端界面时，Kiki 提供两条桌面控制路径。两条路径都不会自动安装或自动接管桌面，必须由你手动安装并确认授权后才会生效：

- **内置电脑控制（[设置 → 能力 → 浏览器与电脑 → 电脑控制](/zh/guides/settings#电脑控制)）**：在 Kiki 服务机上下载并校验固定版本的开源执行器，注册桌面控制连接。页面的**模型使用倾向**默认设为**更不倾向**——除非你或你的规则明确要求，否则模型优先使用已有的 CLI、API、MCP、短脚本和浏览器专用能力；当你处理交互式桌面任务时，可以随时切为**更倾向**。主智能体可直接按权限规则调用桌面工具，子智能体则需显式授权开启。
- **[Kimi Computer Use 插件](/zh/customization/plugins#kimi-computer-use)**：从直链安装的官方桌面控制插件，让智能体直接对桌面应用执行点击、拖拽、滚动与输入。macOS 版在系统设置中授予辅助功能与屏幕录制权限后，可在后台静默运行、不抢占你的鼠标；Windows 版（WinCU）在真实交互式桌面会话中运行，无需额外系统权限弹窗，但执行动作时会短暂激活目标窗口并使用你的真实键鼠。
