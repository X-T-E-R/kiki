# 功能介绍

Kiki 是一个跑在你机器上的开源 AI 智能体工作台。你把一个文件夹和要达成的结果交给它——摸清陌生代码库、拆读一堆 PDF 与表格、写出一份报告，或是完成跨文件的工程改动——主会话会自己做计划，在活儿能干净切开时派出子智能体分头推进，并跨轮次、跨会话把事情接住。

桌面应用、终端界面（`kiki`）和浏览器界面（`kiki web`）连接同一个本地守护进程，你在任何一个入口开的会话，换个窗口打开还是它。

![Kiki 工作台：主会话派出的子智能体、进行中的目标和一条排队消息同屏可见。](/shots/index/wl-20261005-hero-workbench.zh.png)

第一次用 Kiki？先看 [安装](/zh/getting-started/installation) 和 [首次启动](/zh/getting-started/first-launch)，再回到这里。已经在用？直接按你手头要解决的事跳到对应页面——每一页都会讲清这项能力怎么运作，并链回带完整步骤与字段说明的指南或参考手册。

## 分工、派活与长线推进

当一件事超过单轮对话或单个模型的舒适区时，Kiki 把工作拆到不同角色、不同模型和更长的时间跨度上。

| 页面 | 什么时候看这一页 | 讲什么 |
| --- | --- | --- |
| [一个工作台，好几条线](/zh/features/workbench) | 一件事要分几路同时做，或想让不同角色各用各的模型 | 主会话如何派发上下文隔离的子智能体、为不同角色绑定不同厂商的模型、随时点开子智能体自己的记录，以及跑完自动通知的后台任务 |
| [Agent Profiles](/zh/features/agent-workflows) | 想把常用的工作角色沉淀成可复用的配置 | 用一份 Markdown 定义一类智能体（模型、思考档位、工具白名单、系统提示词与可派发的子智能体）、内置角色与模板（`explore`、`implementer`、`reviewer`），以及约 200 ms 的保存热重载 |
| [长时间的活](/zh/features/long-work) | 活儿要跑一上午、跨几天，或按周期重复 | 跨轮次推进的 `/goal`、智能体忙碌时可逐条指定送达时机的消息队列、定时任务、工作区需求看板、上下文满了之后的续接策略（压缩摘要、清空重开 `Fresh`、自动），以及按全局、工作区、角色分层且可逐条撤销的记忆 |
| [能一起干活的人](/zh/features/people) | 需要记住长期约定的固定搭档，或多角色拉群讨论 | 带独立记忆、长期规则和固定日常对话入口的角色（Persona），以及让两到六个角色或现有线程在主持人和发言预算下围绕同一话题讨论的房间（Room） |

## 看清状态、精细控场与按需扩展

你可以随时看清智能体在干什么、花了多少钱、实际收到了哪句指令，并在不 fork 代码的前提下改写栈里的任意一层。

| 页面 | 什么时候看这一页 | 讲什么 |
| --- | --- | --- |
| [每天用的桌面](/zh/features/daily) | 日常盯盘、给消息留批注，或排查请求为什么慢、花了多少 | 自动折叠的工具步骤、随下一条消息发出的消息批注、收拢待办审批与提问的「需要你」托盘、跟随当前焦点智能体的右栏，以及用量页：区分未知与真实 0 的历史账单、直接点名限流规则的实时队列、预览同意后才启用的无正文外部同步 |
| [每一层都归你](/zh/features/freedom) | 某个模型老用错工具，或你想管住登录方式与审批尺度 | 按全局、模型或智能体覆写任意内置提示词字段（细到单个工具描述，用 `kiki prompt-fields` 核对实际生效文本）、统一管理 OAuth 与 API 连接（支持直接复用本机已有的 ChatGPT 或 Grok Build 登录）、四种权限模式（`manual`、`auto`、`review`、`yolo`），以及生命周期 Hooks |
| [扩展](/zh/features/extend) | 任务超出纯文本，要读 PDF/Office、查数据、操作浏览器或生成多模态内容 | 插件体系（含把本地 PDF/Office 转为可检索 Markdown 的 Kiki Extract、Kiki Writing、Kiki Office Suite、Kiki Notion、Kiki Media、Kimi Datasource 金融与学术查询、驱动你已登录浏览器的 Kimi Browser Extension、操作桌面软件的 Kimi Computer Use）、`/skill` 工作流、MCP 服务器，以及具名可查的联网搜索与抓取通道 |
| [外观](/zh/features/look) | 想让工作台顺眼、耐看，适配自己的阅读环境 | 六套内置浅色/深色皮肤、实时生效的强调色与字体圆角微调、自动保障 WCAG AA 文字对比度的本地图片/视频背景，以及外观包 |

## 跨空间、跨设备与外部工具互通

Kiki 默认把数据留在你本机的家目录里；当你需要切分工作与个人账号、连另一台机器、在手机上审批，或与手头已有的 AI 工具配合时，可以按需打开受控的通道。

| 页面 | 什么时候看这一页 | 讲什么 |
| --- | --- | --- |
| [数据与机器都在你手上](/zh/features/spaces) | 需要隔离工作与个人凭据，或跨多台机器与远程服务器干活 | 凭据可共享或独立的多个空间（Spaces）、提供写作与办公入口的 Work 模式、双向审批的远端 Kiki 连接、不授浏览权的单向 thread bridge、一次性链接的浏览器 Web 访问，以及绑定在会话上的 SSH 主机 |
| [手机会话](/zh/features/phone) | 人不在电脑前，想用手机接着聊或批掉卡住的审批 | 用微信扫码或配置 QQ 把手机聊天绑到角色或会话，忙碌时选择排队或插入当前回合，并直接在手机上回答待处理的提问与审批 |
| [带过来，也接得进外面](/zh/features/ecosystem) | 手头已经在用 Claude Code、Codex、Cursor、Zed 或 JetBrains | 把 Claude Code、Codex、Pi、Grok Build、OpenCode 的历史对话导成可继续工作的 Kiki 会话；通过 `kiki acp` 在 IDE 里使用 Kiki；用 `kiki seat` 为外部工具固定 MCP 调用席位；以及让 Kiki 把外部智能体 harness 当作子智能体引擎来调度 |
