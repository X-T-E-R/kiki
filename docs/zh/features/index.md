# 功能介绍

Kiki 是一个跑在你机器上的开源 AI 智能体工作台。这一组页面按你真正会遇到的顺序走：工作台是什么、怎样描述一个能复用的智能体、它跑在哪个模型和哪一层控制之下、长活怎么持续、能和谁一起干活、每天的窗口什么样、数据和机器在哪里、怎么扩展、别的工具怎么接进来，以及外观。

![Kiki 工作台：主会话派出的子智能体、进行中的目标和一条排队消息同屏可见。](/shots/index/wl-20261005-hero-workbench.zh.png)

第一次用 Kiki？先看[安装](/zh/getting-started/installation)，再回到这里。已经在用？直接跳到你要解决的那一页——每页都链回讲全步骤的指南。

| 页面 | 讲什么 |

| [一个工作台，好几条线](/zh/features/workbench) | 主会话、派发的子智能体、按智能体绑模型、后台任务 |
