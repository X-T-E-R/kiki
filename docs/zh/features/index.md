# Kiki 能做什么

Kiki 是一个跑在你机器上的开源 AI 智能体工作台。你把一个文件夹和想要的结果交给它——摸清陌生代码库、核对一摞 PDF 与表格、写出一份报告，或是完成跨文件的工程改动——主智能体负责拆解计划、把独立的活派给子智能体，并让目标跨轮次留在视线里。

工作文件留在你选定的文件夹里；会话、历史和配置保存在你本机的 Kiki home 下，模型请求只发往你自己连接的供应商或本地服务。桌面应用、终端界面（`kiki`）和浏览器界面（`kiki web`）连接同一个本地守护进程，在一个窗口开的活，换一个窗口接着做。

![Kiki 工作台：主会话派出的子智能体、进行中的目标和一条排队消息同屏可见。](/shots/index/wl-20261005-hero-workbench.zh.png)

第一次用 Kiki？先看 [安装](/zh/getting-started/installation) 和 [首次启动](/zh/getting-started/first-launch)，再回到这里。已经在用？按你想做的事直接往下看——每一节讲清 Kiki 实际能做什么，并链到对应的功能页与设置入口。

## 拆解大任务，调用多模型并行推进

当一件事超过单轮对话或单个模型的承载范围时，Kiki 把工作拆给不同的角色和模型同时推进，并把长线目标与项目记忆留存下来。

### 主会话派发与多模型分工

在 [一个工作台，好几条线](/zh/features/workbench) 中，你只跟主智能体对话；遇到能独立切开的子任务，主智能体会派发上下文隔离的子智能体去跑。你可以把主智能体、探索者和审查者分别绑到不同模型或不同厂商（强推理模型做规划、快模型做探索、另一家厂商做独立审查）。

你可以随时点开任意子智能体查看它自己的记录、直接给它发消息。耗时的 Shell 命令和子智能体可以放进后台运行，结束时自动带回结果通知主会话。

![同一个会话里用了好几种模型：派发树中每个角色绑定不同的模型。](/shots/workbench/workbench-per-role-models.zh.png)

### 用 Markdown 定义可复用角色（Agent Profiles）

不必每次重新交代工作规矩。[Agent Profiles](/zh/features/agent-workflows) 把每个角色写成一份可读可改的纯文本 Markdown：Frontmatter 定模型、思考档位、工具白名单与可派发的子智能体，正文就是起步系统提示词。

除了开箱即用的 `agent`、`general`、`explore` 和内置模板 `implementer`、`reviewer`，你可以按团队规范自建角色。文件保存后约 200 毫秒热刷新并用于新派发，在途会话可通过**重建上下文**应用更新。

### 跨轮次目标、排队、定时任务与记忆

[长时间的活](/zh/features/long-work) 接管跨几小时或几天的任务。用 `/goal` 挂起跨轮次目标，让智能体每轮自检直到完成；智能体正忙时，你发出的新消息进入队列，可逐条指定在空闲后、子智能体完成后或全部后台任务完成后送达。

你还可以设置按本地时区触发的定时提示词（在有 Kiki 进程持有该会话时运行）、安装可选的 `kiki-task-board` 插件管理工作区需求看板、选择上下文接近上限时的续接策略（`Summarize` 摘要、`Fresh` 无模型交接包、`Auto` 自动判断），并用 `/memory` 管理全局、工作区、角色三层可逐条撤销的长期记忆。

![一个进行中的目标，下面排着两条排队消息，每条各自带着发送时机。](/shots/long-work/long-work-goal-queue.zh.png)

### 常驻搭档与多角色讨论房间

想要固定搭档或让多个视角碰撞同一议题时，[能一起干活的人](/zh/features/people) 提供带独立身份、长期约定、专属记忆与固定日常对话入口的角色（Persona），支持 Character Card V3 导入导出。你还可以把两到六个角色或现有会话线程拉进同一个房间，在主持人和默认 12 条的发言预算下围绕同一话题展开讨论。

![一个房间，三个角色在讨论一次发布，每条发言都标着是谁说的。](/shots/people/people-room.zh.png)

## 操控浏览器与电脑桌面

当工作走出纯文本，需要点开网页、操作已登录后台，或是驱动没有 API 的桌面软件时，你可以在 **设置 → 能力 → 浏览器与电脑**（及对应插件）中按需启用浏览器与电脑控制。所有受管驱动、浏览器实例和桌面操作都运行在 Kiki 服务端所在的机器上。

### 浏览器控制：四条接入路由与 CDP 附着

[浏览器控制](/zh/guides/settings#浏览器控制)默认可用，在 `native_browser` 实验开关开启（默认开启）且完成你确认的组件配置与浏览器勾选后，智能体即可通过 [浏览器工具](/zh/reference/tools#浏览器类) 打开页面、读取快照、点击、填表与截图（连接只在请求时启动）：

- **Kimi 浏览器扩展**：操控你日常使用的浏览器，直接沿用已有登录态与 Cookie；由 Kiki 安装插件与本地桥接程序，你只需在 Chrome 或 Edge 商店添加扩展并批准。
- **独立浏览器**：由 Kiki 在服务机上管理一套独立浏览器与专属登录态（不复制日常浏览器 Cookie，默认无头运行，可开启窗口显示），点**一键配置**即可下载所需组件。
- **Codex / ChatGPT 浏览器扩展**：准备桥接组件后，从发现的可用扩展连接候选中选择并保存，浏览器握手成功后即可连接。
- **Ego Lite**：自行从官方渠道安装 Ego Lite 并完成其设置窗口后，在 Kiki 中检查就绪并勾选连接，支持通过 `browser__ego_run` 运行自动化脚本并将截图附回时间线。
- **手动附着（高级）**：在高级折叠区可直接附着到任何已开放 CDP 地址的本机或远端浏览器。

每个来源和每个浏览器都有独立的启用与**允许 Agent 调度**勾选，新会话默认使用哪一个也由你指定。

### 电脑控制：操作服务端桌面与图形界面应用

遇到没有 CLI 或接口的桌面软件、跨软件整理录入或客户端界面走查时，Kiki 提供两条桌面控制路径：

- **内置电脑控制（[设置 → 能力 → 浏览器与电脑 → 电脑控制](/zh/guides/settings#电脑控制)）**：围绕开源执行器管理服务机桌面连接。页面不会自动安装执行器或连接桌面；点击**安装执行器**会下载校验发行物并注册 `kiki-computer` 全局 MCP 连接（安装仅代表文件校验通过，不自动触碰桌面）。模型使用倾向默认为**更不倾向**（优先用 CLI、API、脚本和浏览器工具，仅在你明确要求时动用桌面控制），可按需改为**更倾向**。该能力默认向每个会话的主智能体暴露，子智能体需显式开启 `mcp__kiki-computer__*`；固定版 Windows 执行器仅观察主显示屏，macOS 需在系统设置中授予调用进程所需的桌面权限。
- **[Kimi Computer Use 插件](/zh/customization/plugins#kimi-computer-use)**：通过直链安装的官方桌面插件，支持点击、拖拽、滚动与输入。macOS 版需在系统设置中开启辅助功能与屏幕录制权限，在后台静默运行、不抢占鼠标；Windows 版（WinCU）在交互式桌面会话中运行，无需额外系统授权，但执行操作时会短暂激活目标窗口并占用真实键鼠（若目标应用以管理员运行，Kiki 也需同等权限）。

## 处理文档、表格、数据、网页与多媒体

通过 [扩展](/zh/features/extend)，你可以按任务需要把文档解析、Office 编辑、金融与文献数据、外部工作流以及自定义搜索接入工作台。

- **本地文档提取与 Office 办公**：从 **Official** 插件目录按需安装 `Kiki Extract`（将本地 PDF、Office、HTML 转为可读 Markdown，不改原件；PDF/Office 需本机备好 Python 与 MarkItDown）、`Kiki Office Suite`（在本机创建与编辑 Word、Excel、PowerPoint）、`Kiki Work`（本机核对 CSV/TSV 键并比对两张表，不上传数据）与 `Kiki Writing`（专注手稿面板与续写命令）。
- **专业数据库与外部服务**：安装 `Kimi Datasource`（需 Kimi Code OAuth 登录并消耗套餐额度）即可用自然语言查询股票行情、宏观指标、企业工商、百万级学术文献与中国法律法规；安装 `Kiki Notion` 可检索 Notion 并在指定页面写回简报；`Cloudflare Tunnel` 与 `Kiki Sites` 支持暴露本地服务或部署站点。
- **多模态媒体生成**：通过 `Kiki Media` 插件与 [媒体来源](/zh/customization/plugins#媒体来源) 配置内置的图像、视频、语音生成服务或接入你自己的本地脚本，按需发起生成。
- **可查看的网页搜索与抓取通道**：内置 `WebSearch` 与 `FetchURL` 由可检查的搜索与抓取模块驱动（默认 `duckduckgo.search` 无需密钥即可搜网页，也支持 `github.repositories`、`context7.docs` 等具名通道与多密钥轮换）。在**设置 → 能力 → 搜索与抓取**中可直接查看每条搜索通道的凭据来源，以及网址抓取依次经过的提取器与回退顺序。
- **Agent Skills 与 MCP 服务器**：用一份 Markdown 编写可自动触发或通过 `/skill:<名字>` 调用的 [Agent Skills](/zh/customization/skills)（支持一次空白分隔激活多个 Skill）；或通过 `stdio`、`HTTP`、`SSE` 接入任意 [MCP 服务器](/zh/server/mcp)，让外部工具像内置工具一样接受审批与调用。

![抓取通道页签：一个网址按顺序经过哪些提取器，以及每一级回退到哪里。](/shots/extend/ce-20261005-extend-fetch-chain.zh.png)

## 看清运行花费，定制模型连接、提示词与权限

智能体在做什么、花了多少钱、哪个请求为什么卡住、模型实际收到了什么指令，在工作台里都有直接对应的面板与开关。

### 日常时间线、审批托盘与用量页

[每天用的桌面](/zh/features/daily) 把长任务做成不杂乱的日常界面：已完成的工具步骤自动折叠，你可以在任意消息上挂批注随下一轮一起发出，「需要你」托盘在输入框上方集中收拢待处理的审批与提问，右侧栏始终跟随你当前聚焦的主智能体或子智能体。

侧栏的 **Usage（用量）** 页分四栏回答核心问题：**实时**直接点名正在等待的请求是被哪条并发限制规则（含规则 id）拦住，当场可改上限或暂停规则；**历史**展示带独立完整性标记的 token 与费用趋势（未上报的调用标为未知，绝不伪装成 0）；**额度**查看已配置账号剩余用量；**外部同步**支持把不含正文的统计批次发往 Webhook、VibeCafe 或本地脚本，且必须由你预览载荷并明确同意后才会启用。

![用量页的「实时」页签：按模型统计的进行中与排队计数，一条正在等待的请求写明挡住它的 kimi-cap 规则，下方是并发限制规则列表，一条启用、一条已停用。](/shots/daily/ux-usage-live.zh.png)

### 模型连接、本机登录复用、提示词覆写与权限

[每一层都归你](/zh/features/freedom) 把控制权交到每一个具体环节。在**设置 → 模型与提供商 → 服务与账号**中，API 密钥、OAuth 订阅登录（Kimi Code、ChatGPT/Codex、Grok Build、GitHub Copilot）和本地服务都汇总在一张列表里；对于 ChatGPT（Codex）和 Grok Build，你可以先**检测本机**再直接复用本机已有 App 的登录态并自动续期，无需复制凭据。

遇到某个模型老用错工具，无需复制整份 profile，直接用 [提示词字段覆写](/zh/customization/prompt-fields)（或 `kiki prompt-fields`）按全局、模型或智能体替换单条工具描述或系统段落。配合四种权限模式（`manual`、`auto`、交给审查者判断的 `review`、`yolo`）、Plan 模式以及生命周期 [Hooks](/zh/customization/hooks)，你可以精准管住每一次外部动作。

![提示词字段覆写，细到单个工具的描述，旁边是模型实际会收到的内容的实时预览。](/shots/freedom/ce-20261005-freedom-prompt-overrides.zh.png)

### 界面皮肤、字体微调与对比度保护背景

在 [外观](/zh/features/look) 中，你可以从六套内置浅色与深色皮肤（或外观包、TUI 主题）起步，实时微调强调色、字体、圆角与密度，或放入本地图片与循环视频作为窗口背景。Kiki 会自动测量背景明暗并抬高面板不透明度，确保正文始终满足 WCAG AA（4.5:1）可读对比度。

## 跨空间隔离、连手机，或接入你现有的 IDE 与工具

数据默认留在你的本机 Kiki home 下，同时支持按你的授权跨工作空间、跨机器、跨手机与跨工具协同。

- **多空间隔离、跨机连接与会话内 SSH（[数据与机器都在你手上](/zh/features/spaces)）**：用**空间**把工作与个人 Kiki 分开（凭据可共享也可完全独立，并支持一键开启包含文档办公组件的 Work 模式预设）；通过需双方各自批准的单向**远端连接**或仅传消息不授浏览权的 **thread bridge** 跨机器协作；用 `kiki web` 生成一次性链接把当前工作台开到另一台设备的浏览器里；或通过输入框上方的 **SSH** 控件把远端主机加入当前会话，直接用 SFTP 读写文件、跑远端命令。
- **微信与 QQ 手机会话（[手机会话](/zh/features/phone)）**：人不在电脑前时，在**设置 → 通知与消息**中用微信扫码（无需填令牌）或配置 QQ 机器人，把不同聊天绑定到角色或指定会话。你可以在手机上发消息（选择排队或插入当前回合）、阅读回复，并用数字直接回答待处理的提问与审批。
- **导入历史、接入 IDE 与调用外部引擎（[带过来，也接得进外面](/zh/features/ecosystem)）**：内置历史导入无需插件即可把 Claude Code、Codex、Pi、Grok Build、OpenCode 的旧对话转成可继续的 Kiki 会话或只读归档，并在导入前完整预览保留项与损失项；通过 `kiki acp` 在 Zed、JetBrains 等编辑器里直接驱动 Kiki，或用 `kiki seat` 为 Cursor、Claude Code、Codex 固定入站 MCP 席位；反过来，也可以把 Claude Code、Codex、Cursor、Gemini CLI、Grok Build 等设为子智能体的外部执行引擎，并通过 `allow_kiki_subagents` 与 `kiki_context` 桥接回 Kiki 原生上下文。
