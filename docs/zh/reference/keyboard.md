# 键盘快捷键

本页先介绍 GUI 的线程导航，再按使用场景列出 TUI 键位：通用输入、模式切换、编辑、流式输出、工具输出、审批面板和帮助浏览。在 TUI 中输入 `/help` 可查看命令用法、说明、支持状态及输入快捷键。

## 桌面版与网页版线程导航

在 GUI 的设置 → 快捷键中，可以重绑定**下一个正在运行的线程**和**上一个正在运行的线程**，默认分别为 `Ctrl-Tab` 和 `Ctrl-Shift-Tab`。浏览器占用这两个切换标签页的键位，网页版请改用其他快捷键。已有自定义键位保持不变；如果已有自定义动作占用了 `Ctrl-Shift-Tab`，新增的上一个线程动作会保持未绑定，直到你为它分配空闲键位。

这两个动作在当前窗口会话列表中已加载的运行会话之间循环，范围沿用当前连接以及已获取的工作区、归档范围。顺序按创建时间从新到旧，不按置顶或最近更新时间。当前线程不在运行集合中时，下一个进入首项，上一个进入末项。没有运行线程时不跳转；只有一个时停留在该线程。

运行会话指主 Agent 或 subagent 有活动轮次，或仍有后台工作。只有待审批、待回答、未读输出或置顶标记，不会使会话进入运行集合；仍有工作在运行的会话即使同时需要你处理，也保留在集合中。

通过这两个快捷键、侧栏或快速切换器切换对话后，当前可输入的消息框就绪时会获得一次焦点。草稿及未改变草稿的选区会保留，时间线不会被滚动到消息框。已打开的对话框和终端输入保留焦点；普通 Tab、Shift-Tab 和输入法文字输入不受影响。

## 通用快捷键

以下键位在输入框中始终可用：

| 快捷键 | 功能 |
| --- | --- |
| `Enter` | 提交当前输入 |
| `Shift-Enter` / `Ctrl-J` | 在输入中插入换行（也可以在行尾输入 `\` 再按 `Enter`） |
| `↑` / `↓` | 浏览输入历史 |
| `Esc` | 关闭补全菜单、退出空的 Shell 模式，或退出历史浏览；轮次运行中则中断它（见下文） |
| `Ctrl-C` | 清空草稿；输入框为空时中断正在运行的轮次，空闲时连按两次退出 |
| `Ctrl-D` | 输入框为空时连按两次退出；否则删除光标后的字符 |
| `Ctrl-T` | 待办列表被截断时，展开或折叠完整列表 |

轮次运行中按 `Esc`：输入框为空时立即中断。输入框里有草稿时，第一次只在页脚显示「Press Esc again to interrupt」，1.5 秒内再按一次 `Esc` 才中断，草稿保留；中途按其他键会取消。空闲时 `Esc` 不会改动草稿。用 `Esc` 退出历史浏览时，会恢复按 `↑` 之前的草稿。

`Ctrl-C` 总是先清空非空草稿（`Ctrl--` 可以找回），同一次按键不会中断或退出。

**退出程序**：输入框为空时，1.5 秒内连按两次 `Ctrl-C` 或两次 `Ctrl-D`，或输入 `/exit`。第一次按下后页脚会显示「Press Ctrl+C again to exit」，中途按其他键会取消。退出不会停止正在运行的轮次：会话留在共享的 daemon 中，可用 `kiki -r` 恢复（用 `--ephemeral` 启动的会话会在退出时删除）。在会话选择器里，`Ctrl-C` 只关闭选择器；只有启动时、还没有打开任何会话的选择器里才会退出。

没有 `Esc` 或 `Ctrl` 键时（例如手机键盘），可以用 `/stop` 中断正在运行的轮次，用 `/expand` 切换工具输出的折叠状态，用 `/todos` 展开或折叠被截断的待办列表。

## 模式切换

| 快捷键 | 功能 |
| --- | --- |
| `Shift-Tab` | 切换 Plan 模式 |
| `!` | 在空输入框中进入 Shell 模式 |

按 `Shift-Tab` 可开启或关闭 Plan 模式。开启后，Agent 会优先使用只读工具进行研究和规划，并可写入当前计划文件；`Bash` 按当前权限模式和普通规则处理，不会因 Plan 模式额外发起独立审批。单纯切换模式不会创建空计划文件。再次按 `Shift-Tab` 退出 Plan 模式。

在空输入框中键入 `!` 进入 Shell 模式，可直接运行终端命令。详见[交互与输入](../guides/interaction.md#shell-模式)。

## 输入与编辑

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl-G` | 在外部编辑器中编辑当前输入 |
| `Ctrl-V` | 粘贴剪贴板中的图片或视频（Unix / macOS） |
| `Alt-V` | 粘贴剪贴板中的图片或视频（Windows） |
| `Ctrl--` | 撤销输入编辑，包括恢复被 `Ctrl-C` 清空的草稿 |

撤回会话的最后一轮请使用 `/undo`；`Ctrl--` 只编辑输入框。

按 `Ctrl-G` 会打开外部编辑器，编辑器按以下优先级选择：

1. `/editor` 命令配置的编辑器
2. `$VISUAL` 环境变量
3. `$EDITOR` 环境变量

保存并退出后，编辑内容替换输入框；不保存退出则保持原样。

粘贴图片或视频时，输入框中显示占位符，实际媒体数据在提交时一并发送给模型。优先从系统剪贴板读取；Linux 上会尝试 Wayland 与 X11，WSL 下还会通过 PowerShell 兜底读取 Windows 剪贴板。

## 流式输出期间

流式输出（streaming）期间，输入框依然可以接收输入，并支持以下额外操作：

| 快捷键 | 功能 |
| --- | --- |
| `Esc` | 中断正在运行的轮次；输入框里有草稿时需要连按两次 |
| `Ctrl-C` | 先清空非空草稿；输入框为空时中断活动轮次 |

输入框上方的状态行会显示本轮已运行的时间和中断方法；轮次在等待你审批或回答时，状态行会直接说明这一点。

引导正在运行的轮次、把轮次转入后台这两项操作只在桌面应用中提供；TUI 会把你输入的内容排队，等当前轮次结束后再发送。

## 工具输出

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl-O` | 展开或折叠工具输出 |

历史中存在折叠的工具调用结果时，按 `Ctrl-O` 可在折叠和展开之间切换。

## 审批面板

当 Agent 发起需要确认的工具调用时，TUI 会弹出审批面板。详细审批流程见[交互与输入](../guides/interaction.md#审批流程)，面板内可用键位如下：

| 快捷键 | 功能 |
| --- | --- |
| `↑` / `↓` | 在候选选项之间移动光标 |
| `Enter` | 确认当前选中的选项 |
| `1` ~ `9` | 直接选择对应序号的选项 |
| `Esc` / `Ctrl-C` / `Ctrl-D` | 拒绝当前请求 |
| `Ctrl-E` | 面板包含 diff 或文件内容预览时，展开或折叠完整内容 |
| `Ctrl-O` | 切换其他工具输出的折叠状态 |

需要附带反馈的选项（如「Reject」「Revise」）会在确认后切换到反馈输入态：直接输入反馈文本，按 `Enter` 提交；按 `Esc` 退出反馈输入并回到候选列表。

审批面板会自行弹出，常常正赶上你在打字。在连续半秒没有按键之前，它会忽略 `Enter` 和数字键，免得你正在输入的后半段把它答掉。请求到达时如果你打开着选择器或 `/help`，请求会等你关掉那个对话框后再出现，输入框上方的状态行会提示有审批在等待。

## 弹窗模式

`/help` 会在输入框位置打开可滚动的帮助。命令用法和说明随终端宽度换行；关闭后回到未改动的输入草稿。帮助面板内可用键位如下：

| 快捷键 | 功能 |
| --- | --- |
| `↑` / `↓` | 单行滚动 |
| `PageUp` / `PageDown` | 每次滚动 10 行 |
| `Esc` / `Enter` / `q` / `Q` | 关闭面板 |
