# Example appearance packs

`dusk-harbor/` is a complete Kiki appearance pack: colors for light and dark, a picture for light, a looping video with a still poster for dark, and a preview for the pack list. All art is procedurally generated and released under CC0-1.0.

To install it, zip the folder's contents (or the folder itself) and use **Settings › Appearance › Appearance packs › Import pack**, or copy the folder into `<KIKI_HOME>/themes/` on the server host. The format is documented in `docs/en/customization/skins.md`.
