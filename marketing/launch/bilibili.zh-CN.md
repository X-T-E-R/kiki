# B站视频（6–7 分钟）

主线偏「强大」：一段**真实录屏**。一个 Kiki 主会话连续跑几个小时，同时带好几条线，中途接受你改需求，某条线挂了能恢复。录制规范见 [demo-storyboard.md](demo-storyboard.md)（3–5 分钟版是本片主体）。

## 标题备选

1. 我让一个 AI 带着一队不同模型干了一下午活（开源工具 Kiki 实录）
2. 强模型拆活、DeepSeek 干活、换一家模型审：一个主会话跑几个小时的真实录屏
3. 不用来回切窗口了：AI 自己派活、后台跑、跑完自己知道

## 封面文字备选

- 「一个 AI 带一队模型」＋ 小字「真实录屏 · 开源」
- 「它忙它的，我说我的」
- 「几个小时，好几条线，一个会话」

封面用录屏帧：派发树展开、每条线旁边的模型名清晰可见。必须按隐私清单打码。

## 分章节脚本

| 时间 | 章节 | 画面 | 口播要点 |
| --- | --- | --- | --- |
| 00:00 | 开场 | 录屏快进 10 秒：派发树不断长出新的线 | 「这是一个真实会话，跑了 X 小时（按实际时长填）。今天看它怎么带活。」 |
| 00:30 | 这是什么 | README 首屏 / 桌面应用主界面 | Kiki 是开源的本地智能体工作台；桌面、终端、浏览器共用一个本地守护进程。只说一句，不展开。 |
| 01:00 | 分工 | 智能体文件和派发树里的模型名 | 每个角色一份 Markdown，绑自己的模型：规划用强模型、实现用 DeepSeek、探查用 GLM、审查换一家。不评价模型好坏。 |
| 02:00 | 派活 | 主会话发出任务 → 几条线并行 → 放到后台 | 主智能体自己派子智能体、开后台任务；跑完自动通知它，它不用轮询。 |
| 03:00 | 中途改需求 | 在输入框发消息 → 进队列 → 展开「发送时机」 | 它忙的时候我照样能说话。每条消息选：空闲后、子代理完成后、任务完成后。 |
| 04:00 | 出问题了 | 某条线报错 / 中断 → 主会话看到结果 → 重新派发或接着跑 | 只展示录屏里真实发生的事，不要摆拍；没发生就剪掉这一章。 |
| 05:00 | 活不会丢 | 需求看板、`/goal`、定时任务 | 看板智能体自己读写，换会话也还在；目标跨多轮推进。 |
| 05:45 | 自由的那一半 | `kiki prompt-fields explain` 终端输出 | 提示词每个字段都能按模型改，细到工具描述；你能看到模型收到了什么。 |
| 06:15 | 结尾 | 安装命令 + GitHub 地址 | 0.x，有毛刺；macOS 未签名；Windows 要装 Git for Windows。欢迎提 issue。 |

加速的片段在画面角落标「×N 倍速」。示例场景截图（非录屏）出现时标「示例画面」。
