## 分章节脚本

| 时间 | 章节 | 画面 | 口播要点 |
| --- | --- | --- | --- |
| 00:00 | 开场 | 录屏快进 10 秒：派发树不断长出新的线，每行模型名不同 | 「让贵的模型只干它擅长的那一步。一件事，几家模型分工做——你的智能体，你说了算。」 |
| 00:30 | 这是什么 | README 首屏 / 桌面应用主界面 | Kiki 是开源（MIT）的本地智能体工作台，作为服务跑在你自己的机器上，桌面、终端（`kiki`）、浏览器（`kiki web`）和手机看到的是同一场工作。工作文件留在本机文件夹，模型请求只发往你自己连接的供应商或本地服务。 |
| 01:00 | 分工 | 智能体文件和派发树里的模型名 | 每个角色一份 Markdown，绑自己的模型：规划和验收用强模型、实现用 DeepSeek、探查用快模型、审查换一家厂商。不评价模型好坏。 |
| 01:45 | 每个模型都有自己的专武 | 设置 → 模型里的 Recipe 选择面板 + `kiki-recipes` 页面 | Claude Code 是照着 Claude 调的，Codex 是照着 GPT 调的；Kiki 用配方（Recipe）给接进来的每个原生模型单独调——Recipe 把提示词、模型设置和可选脚本 Hook 打包在一起，装一次绑在模型上，每个绑定可单独选开关。我在公开仓库发布了五套（GPT-6.1 Sol、GPT-6 Astra、DeepSeek V4.1、Gemini 4 Argon、Gemini 3.8 Flash）；每个模型就像一个性格不同的孩子，算是哄好了好几个脾气各异的模型，比如让 DeepSeek V4.1 动手前先推演机理和反例。外部执行器跑的回合不套用 Recipe。 |
| 02:30 | 派活与队列 | 主会话发出任务 → 几条线并行 → 放到后台；输入框消息进队列并展开「发送时机」 | 主智能体自己派子智能体、开后台任务，跑完自动通知它不用轮询；它忙的时候我照样发消息进队列，每条选「空闲后 / 子代理完成后 / 任务完成后」。 |
| 03:30 | 出问题了 | 某条线报错 / 中断 → 主会话看到结果 → 重新派发或接着跑 | 只展示录屏里真实发生的事，不要摆拍；没发生就剪掉这一章。 |
| 04:30 | 活能接着做与改提示词 | `/goal`、需求看板插件、`kiki prompt-fields explain` 终端输出 | 可选插件 `kiki-task-board` 留住跨会话需求卡片；提示词每个字段都能按模型改，细到工具描述，`explain` 能看模型最终收到什么；除了代码也能按需装插件拆本地 PDF、核对表格、写长文。 |
| 05:30 | 结尾 | 安装命令 + GitHub 地址 | `0.x`（`0.5.1`），有毛刺；macOS 未签名；Windows 要装 Git for Windows。欢迎提 issue。 |

加速的片段在画面角落标「×N 倍速」。示例场景截图（非录屏）出现时标「示例画面」。

## 简介 / 标签

简介：让贵的模型只干它擅长的那一步。开源本地智能体工作台 Kiki（MIT）实录：一件事，几家模型分工做——强模型规划验收、便宜模型做具体改动、换一家模型审查，支持给每个原生模型安装配方（Recipe）；服务跑在你自己的机器上，桌面、终端、浏览器和手机看到同一场工作。

标签：AI编程、开源、DeepSeek、大模型、智能体、程序员、效率工具
