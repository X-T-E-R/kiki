## 正文

最近在用自己做的一个开源工具 Kiki 干活，分享一下 🙋

以前用 AI 写代码，基本是一个窗口一个对话，我得来回切。现在是一个主会话带着好几条线：它自己派「小弟」去干活，强模型负责拆任务，便宜的 DeepSeek、GLM 跑杂活，审查换另一家模型。

最爽的几点：
✅ 活丢到后台，跑完它自己会收到通知
✅ 它忙的时候我也能发消息，还能挑什么时候发
✅ 需求写在看板上，关掉会话也还在
✅ 每个智能体就是一份 Markdown，之前写的 Claude Code agent 文件直接能用

电脑端 App、终端、浏览器都能用，数据都在自己电脑上。MIT 开源，还在早期版本，有 bug 很正常～

GitHub 搜 X-T-E-R/kiki（小红书不放外链，评论区也可以问我）
