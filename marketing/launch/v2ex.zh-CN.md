# V2EX（分享创造）草稿

**节点：** 分享创造

**标题：** 做了个开源的本地 AI 智能体工作台 Kiki：Claude Code 的 agent 文件直接能用，每个角色可以挂不同厂商的模型

**正文：**

MIT 开源，自己每天都在用：https://github.com/X-T-E-R/kiki

起因很简单：我想让智能体的每一层都能被我打开、被我改。现在它能做到这些：

- **模型随便配。** 每个角色单独绑模型。我自己的用法是主会话用海外模型做规划，DeepSeek、GLM 跑杂活，审查再换一家。子智能体没绑模型会直接报错，不会悄悄用上最贵的那个。
- **智能体就是文件。** 一个智能体一份 Markdown，frontmatter 写工具、模型、能派发谁，正文是系统提示词。手上的 Claude Code、OpenCode agent 文件直接放进去就能用，改完约 200ms 生效。
- **提示词随便改。** 内置提示词每个字段都能覆写，细到单个工具的描述，而且可以只对某个模型生效。便宜模型老是用错某个工具，就单独给它改那个工具的描述。`kiki prompt-fields explain` 能看到最终生效的值和它来自哪一层。
- **数据在本地。** 桌面应用、终端、浏览器三个入口共用一个本地守护进程，不走云端中转。

另外也能扛长时间的活：主智能体自己派子智能体、开后台任务，跑完自动通知它；它忙的时候我照样发消息，每条可以选「空闲后 / 子代理完成后 / 任务完成后」再发；工作区有块需求看板，换了会话也还在。
